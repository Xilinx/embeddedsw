xwdttb_winwdt_qamode_example.c File Reference

Overview

Demonstrates the Q&A mode of the Window Watchdog Timer.

This file contains an example that demonstrates Q&A functionality of the Window Watchdog.

Note
This example assumes that the reset output of the WdtTb device is not connected to the reset of the processor. This example does not return if the interrupts are not working.
