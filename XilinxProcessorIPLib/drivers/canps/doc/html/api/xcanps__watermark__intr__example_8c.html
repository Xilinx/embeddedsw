xcanps_watermark_intr_example.c File Reference

Overview

Demonstrates XCanPs driver usage with Rx watermark interrupts.

Note
The Baud Rate Prescaler Register (BRPR) and Bit Timing Register (BTR) are set up for a CAN baud rate of 40Kbps. This setting assumes a CAN clock of 24MHz. Modify these values based on the desired baud rate and the CAN clock frequency. For more information see the CAN 2.0A, CAN 2.0B, ISO 11898-1 specifications.

Demonstrates XCanPs driver operation with Rx watermark interrupts. 


The example configures the device for internal loop back mode. It then sends multiple CAN frames and receives the same number of CAN frames using the Rx Watermark Interrupt.


Parameters

  

    
[out]CanInstPtrPointer to the instance of the CAN driver which is going to be connected to the interrupt controller. 

    
[in]BaseAddressBase address of the device.

  

  




Returns
XST_SUCCESS if successful, otherwise driver-specific error code.


Note
- In XSCT/classic flow, DeviceId is used to look up the device configuration.
    

  • If the device is not working correctly, this function may enter an infinite loop and never returns to the caller.
