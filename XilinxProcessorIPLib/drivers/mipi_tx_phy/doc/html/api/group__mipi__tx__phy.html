u32 XMipi_Tx_Phy_DynamicLineRateConfig ( XMipi_Tx_Phy *  InstancePtr,
UINTPTR  PllBaseAddr,
u32  LineRate 
)

This function configures the dynamic line rate for the MIPI TX PHY by programming the MMCM registers and NPI X5PLL registers.

The driver disables the PHY, programs the MMCM via XMipi_Tx_Phy_MmcmConfig, delegates the PLL register programming to XMipi_Tx_Phy_XPllConfig, and re-enables the PHY.

Parameters
InstancePtris the XMipi_Tx_Phy instance to operate on.
PllBaseAddris the base address of the X5PLL register space.
LineRateis the desired line rate in Mbps (400-4500 Mbps).
Returns
  • XST_SUCCESS if line rate configuration is successful.
  • XST_FAILURE if the line rate is out of supported range or dynamic line rate is not enabled in hardware.
Note
The PHY is disabled before MMCM and PLL reprogramming and re-enabled after the sequence completes to ensure a clean transition.
