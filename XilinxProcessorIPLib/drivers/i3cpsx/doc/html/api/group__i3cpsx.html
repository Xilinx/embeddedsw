Typedef Documentation

typedef void(* XI3cPsx_HjHandler)(void *CallBackRef)

Defines a callback for Hot-Join requests.

The Hot-Join handler data type allows the application to define a callback function the driver invokes (from interrupt context) to flag a Hot-Join request. The joining target is NOT yet enrolled when this is called; the application must run enrolment (ENTDAA) via XI3cPsx_HotJoinDaa() from thread context.

Parameters
[in]CallBackRefThe callback reference passed in by the upper layer when setting the Hot-Join handler, and passed back to the upper layer when the callback is invoked.
typedef void(* XI3cPsx_IbiHandler)(void *CallBackRef, u32 DevAddr, u8 *Payload, u32 PayloadLen)

Defines a callback for In-Band Interrupt (SIR) events.

The IBI handler data type allows the application to define a callback function to respond to In-Band Interrupt (SIR) events received from a target. This function is executed in interrupt context, so the amount of processing should be minimized.

Parameters
[in]CallBackRefThe callback reference passed in by the upper layer when setting the IBI handler, and passed back to the upper layer when the callback is invoked.
[in]DevAddrThe dynamic address of the target that raised the IBI.
[in]PayloadPointer to the mandatory-data-byte/payload bytes drained from the IBI queue (valid for PayloadLen bytes). Only valid for the duration of the callback.
[in]PayloadLenThe number of valid payload bytes.
typedef void(* XI3cPsx_IntrHandler)(void *CallBackRef, u32 StatusEvent)

Defines a callback for I3C interrupt events.

The handler data type allows the application to define a callback function to respond to interrupt events in the system. This function is executed in interrupt context, so amount of processing should be minimized.

Parameters
[in]CallBackRefThe callback reference passed in by the upper layer when setting the callback functions, and passed back to the upper layer when the callback is invoked. Its type is not important to the driver, so it is a void pointer.

Initializes the I3C bus.

Parameters
[in,out]InstancePtrPointer to the XI3cPsx instance.
Returns

Note
SCL timing must be programmed before calling this function. void XI3cPsx_EnableHotJoin ( XI3cPsx *  InstancePtr)

Enables Hot-Join request acceptance.

It clears DEVICE_CTRL.HOT_JOIN_CTRL so the controller ACKs a Hot-Join request, and lazily enables the IBI threshold interrupt (shared with SIR) since Hot-Join requests are reported through the same IBI queue.

Parameters
[in]InstancePtrPointer to the XI3cPsx instance.
Note
A Hot-Join sets HotJoinPending and invokes the Hot-Join handler from the ISR. The blocking ENTDAA enrolment is deferred: the application must call XI3cPsx_HotJoinDaa() from thread context to assign the new target its dynamic address.

s32 XI3cPsx_EnableIbi ( XI3cPsx *  InstancePtr,
u32  DevIndex 
)

Enables In-Band Interrupt (SIR) reception for a single target.

It clears the SIR reject in the target's DAT entry and in the global reject register, sets IBI-with-data if the target's BCR advertises a mandatory data byte, lazily enables the IBI threshold interrupt, and sends ENEC(SIR) to the target.

Parameters
[in,out]InstancePtrPointer to the XI3cPsx instance.
[in]DevIndexThe Device Address Table index of the target (same index used during dynamic address assignment).
Returns
  • XST_SUCCESS if everything went well.
  • XST_SEND_ERROR if the ENEC(SIR) payload could not be sent.

void XI3cPsx_RecoverFromError ( XI3cPsx *  InstancePtr)

Brings the controller back to a usable state after a transfer error.

An error response such as a receive buffer overflow leaves the core halted, and it stays halted until RESUME is written. The FIFOs are cleared after that because a transfer aborted part way through can leave untransmitted data behind in the TX FIFO.

This does not restore a target that has latched an error into its CCC_DEVICE_STATUS; that register is read only and needs the controller to read it with GETSTATUS.

Parameters
[in,out]InstancePtrPointer to the XI3cPsx instance.
Note
RESUME must be written before the FIFOs are reset. Resetting the FIFOs of a halted core leaves it halted.

void XI3cPsx_SlaveInterruptHandler ( XI3cPsx *  InstancePtr)

Handles interrupts in slave mode.

It does the protocol handling for the interrupt-driven transfers.

Completion events and errors are signaled to upper layer for proper handling.

The interrupts that are handled are:

  • DATA If the instance is sending, it means that the master wants to read more data from us. Send more data, and check whether we are done with this send.

    If the instance is receiving, it means that the master has written more data to us. Receive more data, and check whether we are done with with this receive.

  • COMP This marks that stop sequence has been sent from the master, transfer is about to terminate. However, for receiving, the master may have written us some data, so receive that first.

    It is an error if the amount of transferred data is less than expected.

  • NAK This marks that master does not want our data. It is for send only.
  • Other interrupts These interrupts are marked as error.

[in,out]InstancePtrPointer to the XI3cPsx instance.
