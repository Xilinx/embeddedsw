xi3cpsx_slave_intr_loopback.c File Reference

Overview

Shows I3C slave interrupt-mode loopback.

This file consists of a slave mode design example which uses the Xilinx I3C device in slave interrupt mode in a loopback setup.

The master sends data to the slave. The slave receives the data using interrupt-driven mode. The received data is then verified against the transmitted data. Slave also sends the data to master.

This code assumes that no Operating System is being used.

It's a reference example and the data size should be less than or equal to FIFO size.

int I3cPsxSlaveIntrLoopbackExample ( UINTPTR  BaseAddress)

Runs a slave interrupt loopback test on the I3c device and driver.

This function does a slave interrupt loopback test on the I3c device and driver as a design example. The purpose of this function is to illustrate how to use the XI3cPsx driver in slave interrupt mode.

This function sends data from the master and receives it on the slave through the I3C loopback. It expects the controllers to be in loopback.

This function uses interrupt-driven slave mode and polled master mode of the I3C.

Parameters
[in]BaseAddressThe base address of the device.
Returns
  • XST_SUCCESS if successful.
  • XST_FAILURE otherwise.
Note
In XSCT/classic flow, DeviceId is used to look up the device configuration.
