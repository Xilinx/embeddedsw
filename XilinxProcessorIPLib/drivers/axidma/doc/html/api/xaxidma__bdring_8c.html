XAxiDma_Bd
u32 XAxiDma_Bd[XAXIDMA_BD_NUM_WORDS]
The XAxiDma_Bd is the type for a buffer descriptor (BD).
Definition: xaxidma_bd.h:111

Moves the BD pointer ahead by an arbitrary number of BDs.

Wraps around to the beginning of the ring when needed. A wraparound occurs when the new BD pointer is greater than the high address in the ring or when the pointer crosses the 0xFFFFFFFF to 0 boundary.

Parameters
[in]RingPtris the BD ring that contains BdPtr.
[out]BdPtris the starting BD pointer on entry and the updated BD pointer on return.
[in]NumBdis the number of BD spaces to advance.
Note
Usable only when the DMA is in scatter-gather mode.

Referenced by XAxiDma_BdRingAlloc(), XAxiDma_BdRingFree(), XAxiDma_BdRingFromHw(), XAxiDma_BdRingToHw(), and XAxiDma_BdRingUnAlloc().

XAxiDma_Bd
u32 XAxiDma_Bd[XAXIDMA_BD_NUM_WORDS]
The XAxiDma_Bd is the type for a buffer descriptor (BD).
Definition: xaxidma_bd.h:111

Moves the BD pointer backwards by an arbitrary number of BDs.

Wraps around to the end of the ring when needed. A wraparound occurs when the new BD pointer is less than the base address in the ring or when the pointer crosses the 0xFFFFFFFF to 0 boundary.

Parameters
[in]RingPtris the BD ring that contains BdPtr.
[out]BdPtris the starting BD pointer on entry and the updated BD pointer on return.
[in]NumBdis the number of BD spaces to move backward.
Note
Usable only when the DMA is in scatter-gather mode.

Referenced by XAxiDma_BdRingUnAlloc().
