gpiops Documentation

The Xilinx PS GPIO driver supports the Xilinx PS GPIO Controller.The GPIO Controller supports the following features:

  • Six banks
  • Masked writes (there are no masked reads)
  • Bypass mode
  • Configurable Interrupts (Level/Edge)

This driver is intended to be RTOS and processor independent. The layer above this driver must satisfy any needs for dynamic memory management, threads or thread mutual exclusion, virtual memory, or cache control.

The following lists show the GPIO bank and pin mapping for each platform.

  • Zynq: PS GPIO contains four banks and 118 pins.
    • Bank 0 MIO pins 0 - 31
    • Bank 1 MIO pins 32 - 53
    • Bank 2 MIO pins 54 - 85
    • Bank 3 EMIO signals 86 - 117
  • Zynq Ultrascale+ MP: PS GPIO contains six banks and 174 pins.
    • Bank 0 MIO pins 0 - 25
    • Bank 1 MIO pins 26 - 51
    • Bank 2 MIO pins 52 - 77
    • Bank 3 EMIO signals 78 - 109
    • Bank 4 EMIO signals 110 - 141
    • Bank 5 EMIO signals 142 - 173
  • Versal: Two GPIOPS instances, PMC GPIO and PS GPIO.
    • PMC GPIO contains four banks and 116 pins.
      • Bank 0 MIO pins 0 - 25
      • Bank 1 MIO pins 26 - 51
      • Bank 3 EMIO signals 52 - 83
      • Bank 4 EMIO signals 84 - 115
    • PS GPIO contains two banks and 58 pins.
      • Bank 0 MIO pins 0 - 25
      • Bank 3 EMIO signals 26 - 57

This driver supports all the features listed above, if applicable.

Driver Description

The device driver enables higher layer software (for example, an application) to communicate with the GPIO.

Interrupts

The driver provides interrupt management functions and an interrupt handler. You need to provide callback functions when you use this driver. An interrupt handler example is available with the driver.

Threads

This driver is not thread safe. The layer above this driver must satisfy any needs for threads or thread mutual exclusion.

Asserts

All Xilinx drivers use asserts to enforce constraints on argument values. To turn off asserts on a system-wide basis, define the NDEBUG identifier at compile time. By default, asserts are turned on. It is recommended that you leave asserts on during development.

Building the driver

The XGpioPs driver is composed of several source files. This structure allows you to build and link only those parts of the driver that are necessary.
