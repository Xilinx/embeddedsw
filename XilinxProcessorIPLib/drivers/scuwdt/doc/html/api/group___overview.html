Disable register

Writes to this register switch from watchdog mode to timer mode.

The software must write 0x12345678 and 0x87654321 successively to the Watchdog Disable Register so that the watchdog mode bit in the Watchdog Control Register is set to zero.

s32 XScuWdt_SelfTest ( XScuWdt *  InstancePtr)

Runs a self-test on the WDT.

This test stops the watchdog and writes a value to the watchdog load register. It then starts the watchdog and verifies the value read from the counter register is less than the value written to the load register. It then restores the control register and the watchdog load register.

Parameters
[in]InstancePtrPointer to the XScuWdt instance.
Returns
  • XST_SUCCESS if self-test was successful.
  • XST_FAILURE if the WDT is not decrementing.
