xuartns550_low_level_example.c File Reference

Overview

Demonstrates low-level UART NS550 driver usage.

This file contains a design example using the low-level driver functions and macros of the UART NS550 driver.

int XUartNs550_LowLevelExample ( UINTPTR  UartBaseAddress)

Performs a minimal low-level test on the UART device.

Tests the UART device using the low-level driver macros and functions.

This function sends data and expects to receive the data through the UART. A physical loopback must be done with the transmit and receive signals of the UART.

Parameters
[in]UartBaseAddressBase address of the UARTNS550 device and is the XPAR_<UARTNS550_instance>_BASEADDR value from xparameters.h.
Returns
XST_SUCCESS if successful, XST_FAILURE if unsuccessful.
