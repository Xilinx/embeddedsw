u8  MutexNumber,
u32 *  Locked,
u32 *  Owner 
)

Gets the lock status and owner of a Mutex.

Gets the current status of a Mutex lock within a Mutex device.

Parameters
[in]InstancePtrPointer to the XMutex instance to be worked on.
[in]MutexNumberSpecific Mutex lock within the device to operate on. Each device may contain multiple Mutex locks. The Mutex number is a zero based number with a range of 0 - (InstancePtr->Config.NumMutex - 1).
[out]LockedPointer where the current lock status is stored. Sets memory pointed to by 'Locked' to 1 if the Mutex is locked and 0 if it is unlocked.
[out]OwnerPointer where the current owner status is stored. If the Mutex is locked, the memory pointed to by 'Owner' is updated to reflect the CPU ID that has currently locked this Mutex.

void XMutex_Lock ( XMutex *  InstancePtr,
u8  MutexNumber 
)

Locks a Mutex within a Mutex device.

Locks a particular Mutex lock within a Mutex device. Call blocks till the Mutex is locked.

Parameters
[in]InstancePtrPointer to the XMutex instance to be worked on.
[in]MutexNumberSpecific Mutex lock within the device to operate on. Each device may contain multiple Mutex locks. The Mutex number is a zero based number with a range of 0 - (InstancePtr->Config.NumMutex - 1).
Note
  • XMutex_Lock blocks until the caller gets the lock.
  • Use XMutex_Trylock for a non-blocking call. The caller gets the lock if it is available and returns immediately if the lock is not available.

References XMutex_Config::BaseAddress, XMutex::Config, LOCKED_BIT, OWNER_SHIFT, XMU_MUTEX_REG_OFFSET, XMutex_ReadReg, and XMutex_WriteReg.

int XMutex_SelfTest ( XMutex *  InstancePtr)

Runs a destructive self-test on a Mutex core.

Selftest a particular Mutex hardware core.

Parameters
[in]InstancePtrPointer to the XMutex instance to be worked on.
Returns
  • XST_SUCCESS if test was successful.
  • XST_FAILURE if test was not successful.
Note
This test is destructive. It fails if the Mutex is currently being used. This is also a blocking call, if there is another process which has the Mutex, the first lock hangs the test until the other process releases it.

References XMutex::Config, LOCKED_BIT, XMutex_Config::NumMutex, XMutex_GetStatus(), XMutex_IsLocked(), XMutex_Lock(), and XMutex_Unlock().

int XMutex_Trylock ( XMutex *  InstancePtr,
u8  MutexNumber 
)

Tries to lock a Mutex without blocking.

Locks a particular Mutex lock within a Mutex device. Call returns immediately if the Mutex is already locked (This is Non-Blocking call).

Parameters
[in]InstancePtrPointer to the XMutex instance to be worked on.
[in]MutexNumberSpecific Mutex lock within the device to operate on. Each device may contain multiple Mutex locks. The Mutex number is a zero based number with a range of 0 - (InstancePtr->Config.NumMutex - 1).
Returns
  • XST_SUCCESS if locking was successful.
  • XST_DEVICE_BUSY if the Mutex was found to be already locked.
Note
  • This is a non-blocking call. The caller gets the lock if it is available. Otherwise, XST_DEVICE_BUSY is returned.
  • Use XMutex_Lock if you need to block until a lock is obtained.

References XMutex_Config::BaseAddress, XMutex::Config, LOCKED_BIT, OWNER_SHIFT, XMU_MUTEX_REG_OFFSET, XMutex_ReadReg, and XMutex_WriteReg.
