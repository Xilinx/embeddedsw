int SpiXipExample ( XSpi *  SpiInstancePtr,
UINTPTR  BaseAddress 
)

Reads data from Flash memory in the way any memory is accessed.

The purpose of the function is to illustrate how to use SPI device in XIP Mode.

The function reads data from Flash in the same way any other memory is accessed

Parameters
[in]SpiInstancePtrPointer to the instance of Spi component.
[in]BaseAddressBase address of the device.
Returns
XST_SUCCESS if successful, XST_DEVICE_NOT_FOUND if the SPI configuration is not found, otherwise XST_FAILURE.
Note
In XSCT/classic flow, the device configuration is looked up by DeviceId.

References XSpi_Config::BaseAddress, XSpi::FlashBaseAddr, XSpi_CfgInitialize(), and XSpi_LookupConfig().
