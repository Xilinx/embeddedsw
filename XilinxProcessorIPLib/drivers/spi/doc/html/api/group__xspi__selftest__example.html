int SpiSelfTestExample ( UINTPTR  BaseAddress)

Runs a selftest and loopback test on the SPI device and XSpi driver as an example.

The purpose of the function is to illustrate how to use the XSpi component.

Parameters
[in]BaseAddressBase address of the device.
Returns
XST_SUCCESS if successful, XST_DEVICE_NOT_FOUND if the SPI configuration is not found, XST_FAILURE if unsuccessful
Note
In XSCT/classic flow, the device configuration is looked up by DeviceId.

References XSpi_Config::BaseAddress, XSpi_CfgInitialize(), XSpi_LookupConfig(), and XSpi_SelfTest().
