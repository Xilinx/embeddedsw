xspi_numonyx_flash_quad_example.c File Reference

Overview

Implements a design example using the SPI driver (XSpi) and axi_qspi device with a Numonyx quad serial flash device in the interrupt mode.

The example erases a Sector, writes to a Page within the Sector, reads back from that Page and compares the data.

The example has been tested with an N25Q128 device on KC705 and ZC770 board. The bytes per page (PAGE_SIZE) in N25Q128 is 256.
