xspi_eeprom_example.c File Reference

Overview

Implements a design example using the SPI driver (XSpi) and a serial EEPROM device.

The hardware which this example runs on must have a serial EEPROM (Microchip 25XX320 or 25XX160) for it to run. The example has been tested with the SPI EEPROM on the ML410 platform for PPC processor.
