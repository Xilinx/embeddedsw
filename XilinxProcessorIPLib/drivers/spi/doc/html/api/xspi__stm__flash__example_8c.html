xspi_stm_flash_example.c File Reference

Overview

Implements a design example using the SPI driver (XSpi) and hardware device with an STM serial Flash device (M25P series) in the interrupt mode.

The example erases a Sector, writes to a Page within the Sector, reads back from that Page and compares the data.

The example has been tested with an M25P16 device. The bytes per page (STM_PAGE_SIZE) in M25P16 is 256.

The example assumes that the underlying processor is MicroBlaze.
