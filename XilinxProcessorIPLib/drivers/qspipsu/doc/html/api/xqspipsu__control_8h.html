xqspipsu_control.h File Reference

Overview

Declares the intermediate control functions of the QSPIPSU driver.

The xqspipsu_control.h file is the header file for the implementation of the QSPIPSU driver. Generic QSPI interface allows for communication to any QSPI slave device. GQSPI contains a GENFIFO into which the bus transfers required are to be pushed with appropriate configuration. The controller provides TX and RX FIFOs and a DMA to be used for RX transfers. The controller executes each GENFIFO entry noting the configuration and places data on the bus as required.
