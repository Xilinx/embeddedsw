Performs a read operation.

The default setting is DMA mode.

Parameters
[in,out]QspiPsuPtrPointer to the QSPIPSU driver component to use.
[in]AddressAddress of the first sector which needs to be erased.
[in]ByteCountTotal size to be erased.
[in]CommandCommand used to read data from the flash. Supports normal, fast, dual, and quad read commands.
[out]WriteBfrPtrPointer to the write buffer that contains the data to transmit.
[out]ReadBfrPtrPointer to the read buffer to which valid received data is written.
Returns
XST_SUCCESS if successful, else XST_FAILURE.
