xqspipsu_generic_nand_flash_interrupt_example.c File Reference

Overview

Demonstrates the XQspiPsu driver with a NAND flash in interrupt mode.

This file contains a design example using the QSPIPSU driver (XQspiPsu). This example checks bad block information of single block before erase, writes the data to flash and reads it back in DMA mode. This example runs with GENFIFO Manual start. It runs in interrupt mode.

This example has been tested with the Winbond 512MBits using A53 and R5 processors.
