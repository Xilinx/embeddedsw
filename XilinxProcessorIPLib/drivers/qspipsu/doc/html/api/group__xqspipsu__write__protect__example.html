int FlashEnterExit4BAddMode ( XQspiPsu *  QspiPsuPtr,
unsigned int  Enable 
)

Enters or exits the 4-byte addressing mode of the flash device.

As per the Micron and ISSI specifications, a write enable command is issued before the command to enter 4-byte address mode. Macronix and Winbond flash parts do not require write enable.

Parameters
[in,out]QspiPsuPtrPointer to the QSPIPSU driver component to use.
[in]EnableMode selection: 1 enters 4-byte mode and 0 exits it.
Returns
  • XST_SUCCESS if successful.
  • XST_FAILURE if it fails.

u32  Address,
u32  ByteCount,
u8  Command,
u8 *  WriteBfrPtr 
)

Writes to the serial Flash connected to the QSPIPSU interface.

All the data put into the buffer must be in the same page of the device, with page boundaries on 256-byte boundaries.

Parameters
[in,out]QspiPsuPtrPointer to the QSPIPSU driver component to use.
[in]AddressAddress in the Flash to write the data to.
[in]ByteCountNumber of bytes to write.
[in]CommandCommand used to write data to the flash. The QSPIPSU device supports only the Page Program command to write data to the flash.
[in]WriteBfrPtrPointer to the write buffer to transmit.
Returns
XST_SUCCESS if successful, else XST_FAILURE.
u32 GetRealAddr ( XQspiPsu *  QspiPsuPtr,
u32  Address 
)

Translates the address based on the type of interconnection.

In stacked mode, this function asserts the corresponding slave select.

Parameters
[in,out]QspiPsuPtrPointer to the QSPIPSU driver component to use.
[in]AddressAddress to access (for erase, write, or read).
Returns
Translated address. For single mode, the address is unchanged. For stacked mode, the lower flash size is subtracted. For parallel mode, the address is divided by 2.
Note
This function gets the actual address to work on the flash. It also selects the CS and BUS based on the detected configuration.

int QspiPsuWriteProtectFlashExample ( XQspiPsu *  QspiPsuInstancePtr,
UINTPTR  BaseAddress 
)

Demonstrates the XQspiPsu driver and the flash Write Protect pin.

The example uses the XQspiPsu device driver in single mode with x1 or x2 data mode with flash devices greater than or equal to 128Mb. It also drives the Write Protect pin of the flash device using the GQSPI GPIO.

Parameters
[out]QspiPsuInstancePtrPointer to the instance of the QspiPsu device.
[in]BaseAddressBase address of the device.
Returns
XST_SUCCESS if successful, else XST_FAILURE.
Note
In XSCT/classic flow, DeviceId is used to look up the device configuration.
