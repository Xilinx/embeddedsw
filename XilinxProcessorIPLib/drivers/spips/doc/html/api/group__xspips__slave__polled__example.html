int SpiPsSlavePolledExample ( UINTPTR  BaseAddress)

Illustrates how to use the XSpiPs device driver in Slave mode.

The function reads data from a SPI Master and echoes it back to the Master.

Parameters
[in]BaseAddressThe base address of the device.
Returns
  • XST_SUCCESS if successful
  • XST_FAILURE if not successful
Note
In XSCT/classic flow, the device configuration is looked up based on DeviceId.

References XSpiPs_Config::BaseAddress, MAX_DATA, ReadBuffer, UNIQUE_VALUE, WriteBuffer, XSpiPs_CfgInitialize(), XSpiPs_LookupConfig(), and XSpiPs_PolledTransfer().
