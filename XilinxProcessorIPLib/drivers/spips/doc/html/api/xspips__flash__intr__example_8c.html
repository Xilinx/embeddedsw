xspips_flash_intr_example.c File Reference

Overview

Implements a design example using the SPI driver (XSpiPs) in interrupt mode with a serial flash device.

The example performs transfers in Manual start mode using interrupts. The hardware which this example runs on, must have a serial flash for it to run. The example has been tested with SST25W080.
