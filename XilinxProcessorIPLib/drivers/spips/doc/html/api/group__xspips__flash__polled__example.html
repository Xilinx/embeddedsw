int SpiPsFlashPolledExample ( XSpiPs *  SpiInstancePtr,
UINTPTR  BaseAddress 
)

Illustrates how to use the XSpiPs device driver in polled mode.

The function writes and reads data from a serial flash.

Parameters
[in]SpiInstancePtrPointer to the SPI driver instance to use.
[in]BaseAddressThe base address of the device.
Returns
  • XST_SUCCESS if successful
  • XST_FAILURE if not successful
Note
- If the device slave select is not correct and the device is not responding on bus it reads a status of 0xFF for the status register as the bus is pulled up.
  • In XSCT/classic flow, the device configuration is looked up based on DeviceId.
