s32 XNandPsu_CfgInitialize ( XNandPsu *  InstancePtr,
XNandPsu_Config *  ConfigPtr,
u32  EffectiveAddr 
)

Initializes a specific XNandPsu instance.

Call this function before using the NAND flash device to read or write any data.

Parameters
[out]InstancePtrPointer to the XNandPsu instance.
[in]ConfigPtrPointer to the XNandPsu device configuration structure.
[in]EffectiveAddrBase address of the NAND flash controller.
Returns
  • XST_SUCCESS if successful.
  • XST_FAILURE if the flash initialization or the bad block table scan fails.
Note
First call the XNandPsu_LookupConfig() API, which returns the configuration structure pointer passed as a parameter to the XNandPsu_CfgInitialize() API.

u64  Offset,
u64  Length 
)

Erases the flash.

Skips the bad blocks while erasing.

Parameters
[in]InstancePtrPointer to the XNandPsu instance.
[in]OffsetStarting offset of the flash to erase.
[in]LengthNumber of bytes to erase.
Returns
  • XST_SUCCESS if successful.
  • XST_FAILURE if the erase exceeds the flash size when bad blocks are skipped, or a block erase fails.
Note
Align the Offset and Length to the block size boundary to get better results.
