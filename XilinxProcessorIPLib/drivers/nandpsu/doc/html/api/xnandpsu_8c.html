xnandpsu.c File Reference

Overview

Implements the interface functions of the XNandPsu driver.

Refer to the header file xnandpsu.h for more detailed information.

This module supports NAND flash memory devices that conform to the "Open NAND Flash Interface" (ONFI) 3.0 Specification. This module implements basic flash operations like read, write and erase.

Note
The driver is named nandpsu after the change in naming convention.
