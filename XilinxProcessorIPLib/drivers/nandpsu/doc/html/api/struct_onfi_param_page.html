Detailed Description

Holds the parameter page structure of the ONFI 3.1 specification.

The members form the revision information and features block (Signature to Reserved1), the manufacturer information block (DeviceManufacturer to Reserved2), the memory organization block (BytesPerPage to Reserved3), the electrical parameters block (IOPinCapacitance to Reserved4) and the vendor block (VendorRevisionNum to Crc).
