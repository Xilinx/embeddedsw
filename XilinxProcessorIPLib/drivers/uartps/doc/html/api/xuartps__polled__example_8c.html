xuartps_polled_example.c File Reference

Overview

Demonstrates the XUartPs driver in polled mode using local loopback.

The example runs on the ZynqMP evaluation board (ZCU102). It sends data and expects to receive the same data through the device using the local loopback mode in polled mode by using the XUartPs driver.

Note
If the device does not work properly, the example may hang.
