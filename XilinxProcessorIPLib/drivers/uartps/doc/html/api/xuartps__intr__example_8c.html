xuartps_intr_example.c File Reference

Overview

Demonstrates the XUartPs driver in interrupt mode using local loopback.

The example runs on the ZynqMP evaluation board (ZCU102). It sends data and expects to receive the same data through the device using the local loopback mode in interrupt mode by using the XUartPs driver.

Note
The example contains an infinite loop such that if interrupts are not working it may hang.
