xsysmonpsv_driver.h File Reference

Overview

Declares the driver data structures for the AMD Versal System Monitor.

The SysMon driver supports the AMD System Monitor device on Versal.

The System Monitor device has the following features:

  • Measures and monitors up to 160 voltages across the chip.
  • Provides automatic alarms based on user-defined limits for the on-chip temperature.
  • Provides optional interrupt request generation.

Refer to the hardware device specification for detailed information about the device.
