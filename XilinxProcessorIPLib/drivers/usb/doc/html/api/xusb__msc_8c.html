This function rejects a mass storage command that cannot be serviced. 


The command fails with the whole requested data length as residue and the data phase endpoint is halted: bulk IN for READ, bulk OUT for WRITE. The status is then queued on bulk IN by the caller, where the core holds it until the host clears the halt when bulk IN is the stalled endpoint.


Parameters

  

    
[in]InstancePtris a pointer to the XUsb instance. 

    
[in]EndPointis the endpoint carrying the data phase. 

    
[in]TransferLengthis the data transfer length from the Command Block Wrapper. 

    
[out]CswStatusis a pointer to the status field of the Command Status Wrapper. 

    
[out]CswResidueis a pointer to the data residue field of the Command Status Wrapper. 

    
[out]BlockCountis a pointer to the pending transfer block count. It is cleared when non-NULL. 

    
[out]CmdFlagis a pointer to the command-in-progress flag. It is cleared when non-NULL. 

    
[out]SendStatusis a pointer to the flag that requests the status phase. It is set when non-NULL.

  

  




Returns
None.


Note
Pass NULL for SendStatus when the example does not keep that flag. The caller queues the CSW and records it only after that send succeeds.
