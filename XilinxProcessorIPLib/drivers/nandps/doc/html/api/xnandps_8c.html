xnandps.c File Reference

Overview

Implements the interface functions of the XNandPs driver.

This file contains the implementation of the interface functions for XNandPs driver. Refer to the header file xnandps.h for more detailed information.

This module supports for NAND flash memory devices that conform to the "Open NAND Flash Interface" (ONFI) Specification. This module implements basic flash operations like read, write and erase.
