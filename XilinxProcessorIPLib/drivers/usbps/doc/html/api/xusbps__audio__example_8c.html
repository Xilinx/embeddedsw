This function initializes a XUsbPs instance/driver. 


The initialization entails:


    

  • Initialize all members of the XUsbPs structure.
    • 



Parameters

  

    
[in]InstancePtris a pointer to XUsbPs instance of the controller. 

    
[in]ConfigPtris a pointer to a XUsbPs_Config configuration structure. This structure will contain the requested configuration for the device. Typically, this is a local structure and the content of which will be copied into the configuration structure within XUsbPs. 

    
[in]BaseAddressis the base address of the device.

  

  




Returns
    

  • XST_SUCCESS no errors occurred.
    • 

  • XST_FAILURE an error occurred during initialization.
    •
