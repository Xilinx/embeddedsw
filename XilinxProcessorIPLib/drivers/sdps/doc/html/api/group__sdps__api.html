s32 XSdPs_CfgInitialize ( XSdPs *  InstancePtr,
XSdPs_Config *  ConfigPtr,
UINTPTR  EffectiveAddr 
)

Initializes a specific XSdPs instance so that the driver is ready to use.

Parameters
[in,out]InstancePtrPointer to the XSdPs instance.
[in]ConfigPtrReference to a structure containing information about a specific SD device. The InstancePtr object is initialized for a specific device specified by the contents of Configuration.
[in]EffectiveAddrDevice base address in the virtual memory address space. The caller is responsible for keeping the address mapping from EffectiveAddr to the device physical base address unchanged once the instance is initialized. Unexpected errors may occur if the address mapping changes after the initialization. If address translation is not used, use ConfigPtr->BaseAddress for this device.
Returns
  • XST_SUCCESS if successful.
  • XST_DEVICE_IS_STARTED if the device is already started. It must be stopped to re-initialize.
  • XST_FAILURE if host reset or initialization fails.
Note
Initializes the host controller. Initial clock of 400 KHz is set. Voltage of 3.3 V is selected as that is supported by host. Interrupts status is enabled and signal disabled by default. Default data direction is card to host and 32 bit ADMA2 is selected. Default Block size is 512 bytes.
