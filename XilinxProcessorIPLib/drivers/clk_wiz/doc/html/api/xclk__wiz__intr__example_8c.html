xclk_wiz_intr_example.c File Reference

Overview

Runs the CLK_WIZ interrupt example.

This file contains a design example using the XClk_Wiz driver with interrupts. It generates interrupts for a clock glitch, clock overflow, and underflow. Set up two clocking wizard instances. One instance acts as the clock monitor (enable the clock monitor in the GUI). On the other instance, enable dynamic clock reconfiguration. This example assigns XCLK_WIZ_DYN_DEVICE_ID to clock wizard 1. Modify this value for the dynamic-reconfiguration clocking wizard.

Note
This example requires an interrupt controller connected to the processor and the MIPI CLK_WIZ in the system.
