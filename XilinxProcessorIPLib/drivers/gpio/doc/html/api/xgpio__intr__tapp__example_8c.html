xgpio_intr_tapp_example.c File Reference

Overview

Demonstrates usage of the GPIO driver (XGpio) in interrupt-driven mode.

This file contains a design example using the GPIO driver (XGpio) in an interrupt-driven mode of operation. This example assumes that there is an interrupt controller in the hardware system and the GPIO device is connected to the interrupt controller.

This file is used in the Peripheral Tests Application in SDK to include a simplified test for GPIO interrupts.

The buttons and LEDs are on two separate channels of the GPIO. This separation prevents interrupts when the LEDs turn on and off.
