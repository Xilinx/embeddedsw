xospipsv_flash_polled_example.c File Reference

Overview

Implements a design example using the OSPIPSV driver (xospipsv).

The example writes to flash in IO mode and reads it back in DMA mode. It runs in polled mode. The hardware which this example runs on, must have an octal serial Flash (Micron) for it to run.

The example has been tested with the Micron Octal Serial Flash (mt35xu01gbba).
