Detailed Description

Holds the RX tuning related information.

The RX tuning algorithm compares the data read at every RX tap against a reference pattern which is expected to be pre-programmed in the flash. The application owns the pattern and fills this structure in the driver instance before switching to a PHY mode using XOspiPsv_SetSdrDdrMode(). It supplies the reference data, the location of the pattern in flash, the read instruction used to fetch it and the buffer it is read into.
