int FlashSetSDRDDRMode ( XOspiPsv *  OspiPsvPtr,
int  Mode 
)

Enters the flash device into Octal DDR mode or exits from octal DDR mode (switches to Extended SPI mode).

In a stacked configuration both devices are switched, the controller is switched once and RX tuning is run only against the lower device.

Parameters
[in,out]OspiPsvPtrPointer to the OSPIPSV driver component to use.
[in]ModeEither 1 or 0 if 1 then enter octal DDR mode if 0 exits.
Returns
- XST_SUCCESS if successful.
  • XST_FAILURE if it fails.
Note
The lower flash has to be selected on entry.

u32 GetRealAddr ( XOspiPsv *  OspiPsvPtr,
u32  Address 
)

Translates the address based on the type of interconnection.

In case of stacked, the function asserts the corresponding slave select.

Parameters
[in,out]OspiPsvPtrPointer to the OSPIPSV driver component to use.
[in]AddressWhich is to be accessed (for erase, write or read)
Returns
RealAddr is the translated address - for single it is unchanged; for stacked, the lower flash size is subtracted;
Note
In addition to get the actual address to work on flash the function also selects the CS based on the configuration detected.

int SetBlockProtect ( XOspiPsv *  OspiPsvPtr,
u8  BlockProtectionVal,
u8  IsBottom 
)

Sets the Block Protect bits in the Status register of the device.

User has to pass the BP bits[3:0] value as an argument to the function. The function reads the status register and sets the corresponding BP bits as requested by the user and writes back the status register.

Parameters
[in,out]OspiPsvPtrPointer to the OSPIPSV driver component to use.
[in]BlockProtectionValBlock protection bits value (4-bit value).
[in]IsBottomIndicates whether the protected memory area defined by the block protect bits starts from the top or bottom of the memory.
Returns
XST_SUCCESS or XST_FAILURE.
Note
The function is tested with the Micron device(MT35XU02G).

int SpansionSetEccMode ( XOspiPsv *  OspiPsvPtr)

Configures the ECC mode in Flash device.

In some flashes by default 2-bit ECC is enabled, which prevents byte-programming( <16-Bytes). The function enables byte-programming by setting the ECC configuration to 1-bit error detection/correction.

Parameters
[in,out]OspiPsvPtrPointer to the OSPIPSV driver component to use.
Returns
XST_SUCCESS or XST_FAILURE.
Note
The function is specific to some spansion flashes(S28HS02GT).
