int OspiPsvInterruptFlashExample ( XOspiPsv *  OspiPsvInstancePtr,
UINTPTR  BaseAddress 
)

Illustrates how to use the XOspiPsv device driver using OSPI flash devices greater than or equal to 128Mb.

The function reads data in either DMA or DAC mode.

Parameters
[in]OspiPsvInstancePtrPointer to the instance of the Ospi device.
[in]BaseAddressBase address of the device.
Returns
XST_SUCCESS if successful, else XST_FAILURE.
Note
In XSCT/classic flow, the device configuration is looked up by DeviceId.
