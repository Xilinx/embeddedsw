xdp21txss_hw.h File Reference

Overview

This file contains the register offsets and bit masks for the Display Stream Compression and Forward Error Correction blocks of the Xilinx DisplayPort 2.1 TX Subsystem.

Note
None.

Macro Definition Documentation

#define XDP21_TX_DSC_EN_ACTION_OFFSET   0x0794

Writing one arms transmission of the picture parameter set packet.

#define XDP21_TX_DSC_ENABLE_OFFSET   0x0790

Enables the compressor.

Bit 0 reads back as zero on designs that implement this register write only.

#define XDP21_TX_DSC_ENABLE_OFFSET_ALT   0x0094

Second compressor enable register, the one carrying the slice count.

Bit 0 enables, bits 2 down to 1 hold the division factor and bits 12 down to 8 hold the slice count.

#define XDP21_TX_DSC_NUM_SLICES_MASK   (0x1FU << XDP21_TX_DSC_NUM_SLICES_SHIFT)

Slice count field, holding the picture width divided by the slice width rounded up.

#define XDP21_TX_DSC_NUM_SLICES_SHIFT   8U

Position of the slice count field.

#define XDP21_TX_DSC_PASSTHROUGH   (1 << 2)
