mmi_dc_bypass_test.c File Reference

Overview

This file implements the DC Bypass mode test.

In bypass mode the DC block is bypassed and video from AVPG in PL is routed directly to DP TX.

Multi-stream bypass (MST) programs per-stream AVPG and VTC from xparameters.h for each active bypass stream (up to 4).
