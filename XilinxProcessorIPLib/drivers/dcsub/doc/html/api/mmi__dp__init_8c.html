u32 XDpDc_CheckMstBandwidth ( const RunConfig *  RunCfgPtr,
u8  NumStreams 
)

Checks that the MST streams fit the link time slots before any hardware is programmed, using the PBN and slot math of XMmiDp_ComputeTimeSlot().

The link is the user cap, or HBR3 x4 when auto, so a mode that fails here cannot fit after link training either.

Parameters
RunCfgPtris a pointer to the application configuration structure.
NumStreamsis the number of active streams (1..4).
Returns
XST_SUCCESS if the streams fit, XST_FAILURE otherwise.

References RunConfig::MaxLaneCount, RunConfig::MaxLinkRate, and XDPDC_MST_PAYLOAD_SLOTS.

u32 XDpDc_CheckMstSupport ( RunConfig *  RunCfgPtr)

Set RunCfgPtr->MstMode from SDT mst-mode-en and sink MST_CAP.

SST-only design (mst-mode-en=0): MstMode=0 always. MST design (mst-mode-en=1): MstMode=1 if MST_CAP=1, else connect fails.

Parameters
RunCfgPtris a pointer to the application configuration structure.
Returns
XST_SUCCESS if policy is valid, XST_FAILURE otherwise.

void XDpDc_PrepareVideoStream ( RunConfig *  RunCfgPtr,
u8  StreamId 
)

Prepare one DP video stream: MSA bits per color, pixel mode, video mapping, and standard video mode timing in software state.

Prepare one DP video stream (MSA / mapping / timing structures).

Does not call ConfigureVideoController or EnableVideoStream (those are batched in RunStreamPolicySetup). Still disables the stream via XMmiDp_DisableVideoStream() (VSAMPLE_CTRL) before programming.

Parameters
RunCfgPtris a pointer to the application configuration structure.
StreamIdis the DP stream ID (XMMIDP_STREAM_ID1..ID4).
Note
Caller must clear the video controller before the first stream.

void XMmiDp_SinkPowerCycle ( XMmiDp *  DpPsuPtr)

Power-cycle the sink: SET_POWER down, then up.

On some panels the down/up transition re-asserts HPD and can re-enter the hot-plug handler. Wake delay is unchanged from SinkPowerUp alone (XMMIDP_SINK_POWERUP_DELAY after power-up); only the power-down phase is added relative to a bare SinkPowerUp path.

Parameters
DpPsuPtris a pointer to the XMmiDp instance.

References XMmiDp_SinkPowerDown(), and XMmiDp_SinkPowerUp().
