          u32 XDpDc_AssertDcReset 
          (
          void 
          )
          
        

      





This function asserts the DC block reset and releases SS_CFG_POR in MMI_CRX.RST_DC, whatever state the boot CDO left them in. 


The DC is then configured in reset. XDpDc_ReleaseDcReset() takes it out of reset after DP link training.


Returns
XST_SUCCESS if RST_DC reads back as requested, else XST_FAILURE


Note
None. 



References XMMI_CRX_RST_DC_BLK_MASK.



Referenced by main().











      

        

          u64 XDpDc_GetVidClkBootHz 
          (
          void 
          )
          
        

      





This function returns the video clock rate the XSA programs at boot, which is the rate the PL video pipeline is timed for. 


The rate is read on the first call and cached, so the first call must come before XDpDc_InitClkWiz() reprograms the clock.


Returns
Boot rate in Hz, or 0 if it cannot be read, the clock may already have been reprogrammed or the design has no clock wizard.

          u32 XDpDc_ReleaseDcReset 
          (
          void 
          )
          
        

      





This function releases the DC block reset in MMI_CRX.RST_DC. 


Call it after DP link training and before the DP video stream is configured. The DP video stream registers do not latch while the DC block reset is asserted.


Returns
XST_SUCCESS if RST_DC reads back released, else XST_FAILURE


Note
None.
