xrfdc_ap.c File Reference

Overview

Implements the analog path settings functions of the XRFdc driver.

Contains the interface functions of the Analogue Path Settings in XRFdc driver. Although these features are digital in reality, due to their position in the datapath (being between the crossbar and the converter) they are referred to as "analogue path" blocks. See xrfdc.h for a detailed description of the device and driver.
