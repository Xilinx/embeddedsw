xipipsu_self_test_example.c File Reference

Overview

Demonstrates the XIpiPsu driver by sending an IPI to self.

The example sends an Inter-Processor Interrupt (IPI) message to self and gets a response. Each IPI channel can trigger an interrupt to itself and can exchange messages through the message buffer. The example uses this feature to exercise the driver APIs.

Example control flow:

  • Initializes the IPI and Generic Interrupt Controller (GIC) drivers.
  • Sets up the interrupt system with an IPI handler that inverts the received message and sends it back as the response.
  • Writes a message and triggers an IPI to self.
  • Polls for the response until the timeout expires.
  • The interrupt handler receives the IPI and sends back the response.
  • Reads the received response and verifies it.
  • Prints a success or failure message based on the response check.

Function Documentation

void IpiIntrHandler ( void *  XIpiPsuPtr)

Handles an incoming IPI and sends back the inverted message.

Polls each valid source, checks for a message, reads it, inverts the bits, and sends the inverted message back as a response.

Parameters
[in]XIpiPsuPtrPointer to the IPI instance.
