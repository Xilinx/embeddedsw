Parameters

XIpiPsu_Config* XIpiPsu_LookupConfig ( UINTPTR  BaseAddress)

Looks up the device configuration based on the unique device ID or base address.

The XIpiPsu_ConfigTable[] array holds the configuration information for each device in the system.

Parameters
[in]BaseAddressBase address of the device.
Returns
Pointer to the configuration found, or NULL if the specified device ID or base address is not found. See xipipsu.h for the definition of XIpiPsu_Config.
Note
In the XSCT/Classic flow, DeviceId selects the device configuration. In the system device-tree flow, BaseAddress selects it.

u32  SrcCpuMask,
u32 *  MsgPtr,
u32  MsgLength,
u8  BufferType 
)

Reads an incoming message from a source.

Parameters
[in]InstancePtrPointer to the IPI instance.
[in]SrcCpuMaskDevice mask for the CPU that sent the message.
[out]MsgPtrBuffer that receives the read message. Must not be NULL and must hold at least MsgLength words.
[in]MsgLengthNumber of words to read (each word is 4 bytes). Must not exceed XIPIPSU_MAX_MSG_LEN.
[in]BufferTypeType of buffer (XIPIPSU_BUF_TYPE_MSG or XIPIPSU_BUF_TYPE_RESP).
Returns
  • XST_SUCCESS if successful.
  • XIPIPSU_CRC_ERROR if the CRC check fails (when CRC is enabled).
  • XST_FAILURE if the buffer address is not valid.
