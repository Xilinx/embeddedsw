xwdtps_polled_example.c File Reference

Overview

Demonstrates XWdtPs driver usage in polled mode.

This file contains a design example using the System Watchdog Timer driver (XWdtPs) and hardware device. This function assumes that the reset output of the Watchdog timer device is not connected to the reset of the processor.

int WdtPsPolledExample ( UINTPTR  BaseAddress)

Runs a minimal test on the System Watchdog Timer device and driver.

The test serves as a design example. The purpose of this function is to illustrate how to use the XWdtPs driver.

This function assumes that the reset output of the Watchdog timer device is not connected to the reset of the processor. The function allows the Watchdog Timer to timeout such that a reset occurs if it is connected. If the interrupt output is connected to an interrupt input, handle the interrupts appropriately if the output is enabled.

This function may require some time (seconds or even minutes) to execute because it waits for the Watchdog Timer to expire.

Parameters
[in]BaseAddressBase address of the device.
Returns
XST_SUCCESS if successful, otherwise XST_FAILURE.
Note
In XSCT/classic flow, DeviceId is used to look up the device configuration.
