xrtcpsu_seconds_interrupt_example.c File Reference

Overview

Demonstrates the XRtcPsu seconds feature in interrupt mode.

This file contains a seconds example using the XRtcPsu driver in interrupt mode.

Note
In the example, if interrupts are not working, it may hang.

int RtcPsuSecondsIntrExample ( XRtcPsu *  RtcInstPtr,
UINTPTR  BaseAddress 
)

Runs a minimal test on the RTC device and driver as a design example.

The purpose of this function is to illustrate how to use the seconds feature available in the XRtcPsu driver.

This function shows the seconds interrupt feature.

Parameters
[out]RtcInstPtrPointer to the instance of the RTC driver that is connected to the interrupt controller.
[in]BaseAddressBase address of the device.
Returns
XST_SUCCESS if successful, otherwise XST_FAILURE.
Note
- In XSCT/classic flow, the driver uses DeviceId to look up the device configuration.
  • This function may never return if interrupts are not working.
