s32 Usb_SetConfigurationApp ( struct Usb_DevData *  InstancePtr,
SetupPacket *  SetupData 
)

This function is called by Chapter9 handler when SET_CONFIGURATION command is received from Host.

Handles the SET_CONFIGURATION request from the host; called by the Chapter 9 handler.

Parameters
[in]InstancePtris pointer to Usb_DevData instance.
[in]SetupDatais the setup packet received from Host.
Returns
  • XST_SUCCESS if successful,
  • XST_FAILURE if unsuccessful.
Note
Non control endpoints must be enabled after SET_CONFIGURATION command since hardware clears all previously enabled endpoints except control endpoints when this command is received.

References EpDisable(), ISO_EP, MSG_CONFIG, MSG_UNCONFIG, Usb_DevData::PrivateData, SetConfigDone(), USB_EP_DIR_IN, USB_EP_DIR_OUT, SetupPacket::wValue, and xMainTask.
