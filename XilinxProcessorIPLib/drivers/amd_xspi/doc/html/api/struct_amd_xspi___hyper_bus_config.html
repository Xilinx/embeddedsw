Detailed Description

Describes a HyperBus device.

One entry per supported device, looked up at runtime from the manufacturer and device identifiers read out of the part - IR0 and IR1 for HyperRAM.

This holds ONLY what the device cannot report about itself:

  • Geometry is absent. Density, row/column bits, array rows and the address limit are all decoded from IR0 by the accessors below. So one entry serves every density in a family.
  • Directly readable register fields are not duplicated.

Adding a device is therefore data, not code: append an entry and everything else follows.
