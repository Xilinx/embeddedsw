amd_xspi_hw.h File Reference

Overview

Defines the hardware registers and macros for the AXI XSPI controller.

This header file contains the hardware register definitions and macros for the AXI XSPI controller. This driver supports AXI-Lite mode only.

Interrupt Enable/Status/Event Register bit definitions

The same bit positions are used by all three registers, but they do not behave alike.

AMD_XSPI_ISR reports each condition as a live level, independently of what AMD_XSPI_IER enables, so it can be polled directly and needs no acknowledgement. AMD_XSPI_INT_EVT latches an event only if the matching IER bit was set when the condition fired, and holds it until it is written back.

The polled paths rely on the live behavior. They test AMD_XSPI_ISR once per message without clearing anything between messages. That is only correct because a bit there tracks the current condition rather than remaining set from an earlier transaction.

Transmit Register Instruction Format bit definitions

In Lite mode, the Transmit Register uses a 32-bit instruction format.

User writes instruction first (in 2 AXI-Lite transactions with flags), then command/address/data bytes.
