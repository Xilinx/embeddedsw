Detailed Description

Describes a transfer message for the message-based transfer API.

The message-based transfer API is AmdXspi_PolledTransfer() and AmdXspi_InterruptTransfer().

Each message describes one Lite-mode transaction: command/address followed by a single data phase (transmit OR receive) within one chip-select window.
