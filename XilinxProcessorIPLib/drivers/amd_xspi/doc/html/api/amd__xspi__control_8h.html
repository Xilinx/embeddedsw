amd_xspi_control.h File Reference

Overview

Declares the low-level functions of the AXI XSPI driver.

The amd_xspi_control.h header file for the low-level functions of the AXI XSPI driver. These functions are used internally by the application-facing APIs and are not intended to be called from an application.
