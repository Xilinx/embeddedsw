amd_xspi.c File Reference

Overview

Implements the application-facing APIs of the AXI XSPI driver.

This file contains the implementation of the application facing APIs of the AXI XSPI driver, including the interrupt handler. This driver supports AXI-Lite mode only. Supplying it a design built in any other mode is a configuration error the driver does not check for.
