amd_xspi_control.c File Reference

Overview

Implements the low-level transaction functions of the AXI XSPI driver.

This file contains the low-level transaction functions of the AXI XSPI driver. These functions assemble a Lite mode instruction and sequence the data movement functions to carry out a complete read or write. They also maintain the message queue used by the interrupt driven API.
