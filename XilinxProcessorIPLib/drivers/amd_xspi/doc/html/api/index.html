amd_xspi Documentation

This file contains the software API definition for the AXI XSPI controller driver. The AXI XSPI is a Serial Peripheral Interface (SPI) controller that operates in AXI-Lite mode for register-based data transfers.

Features

  • AXI-Lite mode operation (register-based transfers)
  • Multiple operating modes:
    • Mode 0: Standard SPI half-duplex (single data line)
    • Mode 1: Standard SPI (io0 = MOSI, io1 = MISO)
    • Mode 2: Dual SPI (2 data lines)
    • Mode 3: Quad SPI (4 data lines)
    • Mode 4: xSPI Profile 1.0 (Octal)
    • Mode 5: xSPI Profile 2.0 (HyperBus)
  • Configurable SPI clock modes (CPOL/CPHA: 0, 1, 2, 3). Modes 4 and 5 support clock mode 0 only, and AmdXspi_SetClkMode() rejects the rest.
  • Multiple slave select support (up to 8 slaves)
  • TX and RX FIFOs with occupancy monitoring
  • FIFO ECC errors reported through the error interrupt
  • Interrupt-driven or polled operation

Initialization The driver is initialized using two-step initialization:

  1. AmdXspi_LookupConfig() to get the configuration
  2. AmdXspi_CfgInitialize() to initialize the driver instance

Transfer Operations This driver supports AXI-Lite mode transfers only. The message based API is the primary interface. A message describes one command/address phase and one data phase inside a single chip-select window. That is what an opcode based flash and a HyperBus device both need.

  • AmdXspi_PolledTransfer() to run a message queue to completion
  • AmdXspi_InterruptTransfer() to run one in the background

A message always carries a command/address phase, which the instruction field cannot encode as zero bytes. For a device that needs none, such as a plain SPI part in modes 0 to 3, AmdXspi_Transfer() moves raw bytes instead. Pass NULL for either buffer to make the transfer one-directional.

Interrupts Interrupts are used by AmdXspi_InterruptTransfer() only; the byte oriented interface is polled. A single callback reports the outcome:

  • AmdXspi_SetStatusHandler() to register it
  • AmdXspi_InterruptHandler() as the main ISR
