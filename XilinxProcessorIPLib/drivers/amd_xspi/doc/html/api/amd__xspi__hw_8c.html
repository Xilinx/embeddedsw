amd_xspi_hw.c File Reference

Overview

Implements the register-level functions of the AXI XSPI driver.

This file contains the register level functions of the AXI XSPI driver. These functions operate directly on the controller registers to prepare the FIFOs for a transfer and to manage the interrupt registers.
