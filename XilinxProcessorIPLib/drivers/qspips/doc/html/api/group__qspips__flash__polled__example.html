void FlashWrite ( XQspiPs *  QspiPtr,
u32  Address,
u32  ByteCount,
u8  Command 
)

Writes to the serial FLASH connected to the QSPI interface.

All the data put into the buffer must be in the same page of the device with page boundaries being on 256 byte boundaries.

Parameters
[in,out]QspiPtrPointer to the QSPI driver component to use.
[in]AddressThe address to write data to in the FLASH.
[in]ByteCountThe number of bytes to write.
[in]CommandThe command used to write data to the flash. QSPI device supports only Page Program command to write data to the flash.

int QspiFlashPolledExample ( XQspiPs *  QspiInstancePtr,
UINTPTR  BaseAddress 
)

Illustrates how to use the XQspiPs device driver in polled mode.

The function writes and reads data from a serial FLASH.

Parameters
[in]QspiInstancePtrPointer to the QSPIPS driver to use.
[in]BaseAddressThe base address of the device
Returns
XST_SUCCESS if successful, else XST_FAILURE.
