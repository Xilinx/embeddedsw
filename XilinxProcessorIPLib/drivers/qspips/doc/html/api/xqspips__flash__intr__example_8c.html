xqspips_flash_intr_example.c File Reference

Overview

Implements a design example using the QSPI driver (XQspiPs) in interrupt mode with a serial FLASH device.

The example performs some transfers in Manual Chip Select and Start mode. It is recommended to use Manual CS + Auto start for best performance. The hardware which this example runs on, must have a serial FLASH (Numonyx N25Q, Winbond W25Q, Spansion S25FL, ISSI IS25WP) for it to run. The example has been tested with the Numonyx Serial Flash (N25Q128) and IS25WP series flash parts.
