int QspiPsSelfTestExample ( UINTPTR  BaseAddress)

Runs a selftest on the QSPI device and XQspiPs driver as an example.

The purpose of this function is to illustrate the usage of the XQspiPs driver.

Parameters
[in]BaseAddressThe base address of the device.
Returns
XST_SUCCESS if successful, XST_FAILURE if unsuccessful
Note
In XSCT/classic flow, the device configuration is looked up based on DeviceId.
