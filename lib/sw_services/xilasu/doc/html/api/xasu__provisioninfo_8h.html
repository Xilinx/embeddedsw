xasu_provisioninfo.h File Reference

Overview

This file contains the Provisioning module definitions which are common across the client and server.

The Provisioning module implements the ASU Provisioning Interface (SAS section 12.16). It supports programming the USER eFUSE keys. USER_EFUSE_KEY_0 is programmed in black form only. USER_EFUSE_KEY_1 accepts both black (PUF KEK encrypted) and red (unencrypted) via KeyForm. Red USER key 1 can be used by both PLM and ASU. Black USER key 0 and black USER key 1 are subsystem-exclusive; choose black provisioning with the intended end use case in mind.
