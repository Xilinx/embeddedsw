u32 XAsu_KeyManagerKeyMetadata::CompositeKeyId 

 Composite key identifier, built with

XASU_KM_COMPOSE_KEY_ID():

  • Bits [31:24]: vault ID. Always required.
  • Bits [23:16]: key type, an XAsu_KeyManagerSubVaultType value. Required by the Store Key API, where it may be OR'ed with XASU_KM_KEYTYPE_WRAPPED_BIT_MASK. On the Generate Key APIs, set the same key type the API uses: XASU_AES_SUBVAULT_ID, XASU_IV_SUBVAULT_ID or XASU_KDF_HMAC_SUBVAULT_ID, and for key pairs XASU_RSA_PVT_SUBVAULT_ID, XASU_ECC_PVT_SUBVAULT_ID, XASU_MLDSA_PVT_SUBVAULT_ID or XASU_MLKEM_PVT_SUBVAULT_ID.The returned key IDs carry the sub-vault type of each stored key.
  • Bits [15:0]: 1-based key slot within the sub-vault. 0 requests an auto-assigned slot; other values request a specific slot, which may be rejected if already in use. Key pair APIs apply the requested slot to both the private and public sub-vaults.

Referenced by XAsu_KmValidateKeyMetadata(), XAsu_KmValidateParams(), XAsu_KmValidateXorKeyParams(), XAsu_ProvisionValidateStoreKeyMetadata(), and XAsu_ProvisionValidateXorParams().

u16 XAsu_KeyManagerKeyMetadata::Length

For ECC module: this parameter refers to Curve Length.

For ML-DSA and ML-KEM key pair generation: the public or encapsulation key length of the parameter set named by KeyAttributes, which the request is cross-checked against. For other modules: this parameter refers to Key length.
