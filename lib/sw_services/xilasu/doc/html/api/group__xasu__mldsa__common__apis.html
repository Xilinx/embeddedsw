s32 XAsu_MldsaValidateParams ( const XAsu_MldsaSignVerifyParams *  MldsaParamsPtr)

This function validates the ML-DSA signature generation/verification parameters.

Parameters
MldsaParamsPtrPointer to the XAsu_MldsaSignVerifyParams structure which holds the ML-DSA signature generation/verification parameters.
Returns
  • XST_SUCCESS, if validation of ML-DSA parameters is successful.
  • XST_FAILURE, if any argument is invalid.

Validate ML-DSA params pointer.

Validate the parameter set against the FIPS 204 approved sets.

Validate signature address, which is the output for sign and the input for verify.

Validate message address and length. MsgAddr must be a valid (non-zero) buffer pointer even for an empty message (MsgLen == 0), to match the firmware contract that lets the message stream through the SHA engine: a zero-length update on a valid address is a no-op, while a zero address is rejected by the SHA driver.

Validate the context string length and its address when a context is supplied.

Validate that exactly one of KeyAddr or KeyId is provided, and that a vault sourced key carries no length.

Validate the signing mode before the mode dependent checks below, so that an undefined mode is rejected here rather than travelling to the server to be rejected there.

Validate the pre-hash SHA type and mode, which apply only to HashML-DSA.

Validate the randomness mode, which selects hedged or deterministic signing and is unused for verification. An out of range value would otherwise be taken as hedged rather than rejected, silently signing in a mode the request did not ask for.

s32 XAsu_MldsaValidateSignDerandParams ( const XAsu_MldsaSignDerandParams *  MldsaParamsPtr)

This function validates the parameters of the ML-DSA signature generation which takes its rnd from the request, an algorithm validation only service.

Parameters
MldsaParamsPtrPointer to the XAsu_MldsaSignDerandParams structure which holds the ML-DSA signature generation parameters and the rnd to sign with.
Returns
  • XST_SUCCESS, if validation of ML-DSA parameters is successful.
  • XST_FAILURE, if any argument is invalid.

Validate ML-DSA params pointer.

Validate the signing parameters this command shares with signature generation.

The secret key comes from KeyAddr only, as the key vault is not reachable from a validation command.

rnd must be supplied: a zero address is an error here rather than a request to draw from the TRNG.
