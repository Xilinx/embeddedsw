xasu_mlkem.h File Reference

Overview

This file contains the ML-KEM (FIPS 203) client function prototypes for the ASU ML-KEM module.

The client APIs marshal the request parameters into an IPI command and forward it to ASUFW; the actual encapsulation and decapsulation are performed by the ASUFW ML-KEM module. Key pair generation is not an ML-KEM module command: it is requested through the key manager, using XAsu_KmGenerateMlkemKeyPair.
