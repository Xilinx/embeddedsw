int main (void)
 Main function that initializes the mailbox and ASU client and then calls XAsu_KeyManagerExample, which exercises the KeyManager lifecycle: it creates a key vault, stores a raw ECC P-256 private key, generates an AES-256 key, an AES IV and a raw KDF/HMAC key directly inside the vault, uses the generated AES key/IV for an AES-GCM encrypt/decrypt round-trip and the raw key for both an HMAC and a KDF derivation, generates two ECC P-256 key pairs and uses them for a sign/verify round-trip and an ECDH shared-secret exchange, stores an RSA-4096 public key and runs a key-wrap workflow, exports the whole vault to an encrypted blob and imports it back, and finally deletes the stored key and the vault. Function Documentation

int main ( void  )

Main function that initializes the mailbox and ASU client and then calls XAsu_KeyManagerExample, which exercises the KeyManager lifecycle: it creates a key vault, stores a raw ECC P-256 private key, generates an AES-256 key, an AES IV and a raw KDF/HMAC key directly inside the vault, uses the generated AES key/IV for an AES-GCM encrypt/decrypt round-trip and the raw key for both an HMAC and a KDF derivation, generates two ECC P-256 key pairs and uses them for a sign/verify round-trip and an ECDH shared-secret exchange, stores an RSA-4096 public key and runs a key-wrap workflow, exports the whole vault to an encrypted blob and imports it back, and finally deletes the stored key and the vault.

Returns
  • XST_SUCCESS, if the KeyManager example completes successfully.
  • XST_FAILURE, otherwise.
