Detailed Description

This structure contains the parameters for the Get Device Provisioning Certificate command (SAS section 12.16.2).

The ASU checks the internal exportable key vault for the calling subsystem's provisioning authentication key pair (ECC NIST P-384) and provisioning wrapping key pair (ECIES over NIST P-384); any pair that is missing is generated with the TRNG and stored in the exportable vault. A UDE-signed X.509 certificate is generated over each public key, the DPC container (Device DNA, both certificates and a UDE signature over them) is assembled and returned to the caller at DpcBufAddr, and its actual size is written to DpcActualSizeAddr.
