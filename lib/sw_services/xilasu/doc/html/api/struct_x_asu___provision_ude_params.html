Detailed Description

This structure contains the parameters for the Unique Device Endorsement (UDE) key provisioning command.

The UDE key pair (ECC NIST P-384) is generated inside the ASU (the private key never leaves the ASU), the private key is encrypted with the PUF KEK and programmed into the requested eFUSE slot, and a self-signed X.509 certificate over the generated public key is returned to the caller at CertBufAddr with its actual size at CertActualSizeAddr.

Field Documentation

u64 XAsu_ProvisionUdeParams::CertActualSizeAddr

Address of the caller u32 that receives the actual size in bytes of the generated certificate.

The server returns the size through the response buffer and the client copies it to this address during the callback.
