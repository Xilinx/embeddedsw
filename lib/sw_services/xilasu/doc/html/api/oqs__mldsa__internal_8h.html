oqs_mldsa_internal.h File Reference

Overview

This header is the ASU firmware CONTRACT for the lower-level (internal) ML-DSA entry points exposed by the liboqs "mldsa-native" backend.

liboqs's generic OQS_SIG API only exposes pure + context signing; to support the FULL FIPS 204 surface (HashML-DSA pre-hash, hedged AND deterministic signing, and seed-based KeyGen) the firmware calls these internal symbols directly.

These prototypes MUST match the symbols exported by liboqs.a exactly. The exact link-level names were verified via nm liboqs.a and follow the pattern: PQCP_MLDSA_NATIVE_MLDSA{44|65|87}_C_<function>

The build of liboqs used here does NOT define MLD_CONFIG_CONTEXT_PARAMETER, therefore the functions have NO trailing application-context argument (context-less form). Defining it would add that argument without changing a single symbol name, so the mismatch would link silently. build_liboqs.sh checks for exactly that before it builds: it compiles these declarations alongside mldsa-native's own, where a disagreement is a compile error. Keep the two in step, and see README.liboqs.md section 2 if that check fires.

NOTE: The liboqs drop agent must ensure these symbols are exported (not stripped) from liboqs.a. This header is the single source of truth; the drop must conform to it.

SecKeyPointer to the secret key. 

    
ExternalMuZero when Msg is the raw message, non-zero when Msg is a precomputed mu.
