Detailed Description

This structure contains the parameters for the USER eFUSE key provisioning command.

USER_EFUSE_KEY_0 is always programmed in black form. USER_EFUSE_KEY_1 accepts both black and red via KeyForm. Red USER key 1 is usable by PLM and ASU; black USER key 0 and black USER key 1 are subsystem-exclusive, so choose black provisioning with the end use case in mind. The key source is selected explicitly via KeySource:

  • XASU_PROVISION_KEY_SOURCE_ASU_GENERATED: the ASU generates the key with the TRNG; KeyId and KeyAddr must both be zero. This is the only source permitted for USER_EFUSE_KEY_0.
  • XASU_PROVISION_KEY_SOURCE_VAULT: KeyId selects an AKV key (KeyAddr must be zero).
  • XASU_PROVISION_KEY_SOURCE_USER_BUFFER: KeyAddr supplies a raw key buffer (KeyId must be zero).

u64 XAsu_ProvisionUserEfuseParams::KeyAddr

Address of the user supplied plaintext key buffer.

The buffer must be allocated for 32 bytes (256-bit key). Used only when KeySource is XASU_PROVISION_KEY_SOURCE_USER_BUFFER.

Referenced by XAsu_ProvisionValidateUserEfuseParams().

u8 XAsu_ProvisionUserEfuseParams::KeyForm

Programmed form (XASU_EFUSE_BLACK_KEY or XASU_EFUSE_RED_KEY).

USER_EFUSE_KEY_0 accepts black only; USER_EFUSE_KEY_1 accepts black or red. Red USER key 1 is usable by PLM and ASU; black USER key 1 is subsystem-exclusive.

Referenced by XAsu_ProvisionValidateUserEfuseParams().

u32 XAsu_ProvisionUserEfuseParams::KeyId

Composite key identifier of the AKV key to be programmed (encodes the user-assigned vault ID in bits [31:24], key type in bits [23:16] and key index in bits [15:0]).

Used only when KeySource is XASU_PROVISION_KEY_SOURCE_VAULT.

Referenced by XAsu_ProvisionValidateUserEfuseParams().

u16 XAsu_ProvisionUserEfuseParams::KeyLen

Length of the key in bytes.
