Detailed Description

This structure contains ML-KEM encapsulation/decapsulation parameters.

Both operations share the same layout and are mutually exclusive, so a single generic parameter set is used:

  • For encapsulation, KeyAddr/KeyLen refer to the input public (encapsulation) key and CtAddr is the output ciphertext.
  • For decapsulation, KeyAddr/KeyLen refer to the input secret (decapsulation) key and CtAddr is the input ciphertext. The key is supplied either directly through KeyAddr/KeyLen or from the ASU key vault through KeyId. Exactly one of the two must be non-zero, as enforced by XAsu_KmValidateKeyAddrNdKeyId.
