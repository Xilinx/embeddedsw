Detailed Description

This structure contains info for combining two AES key splits using XOR.

Field Documentation

u64 XAsu_KmXorKeyParams::OutKeyIdAddr

Address where the composite key ID of the combined key is stored.

Required when the destination slot in CompositeKeyId is 0, which requests an auto-assigned slot. Shall be 0 when a slot is selected, as the composite key ID is then already known.

Referenced by XAsu_KmValidateXorKeyParams(), XAsu_KmXorKeys(), and XAsu_ProvisionValidateXorParams().

XAsu_KeyManagerKeyMetadata XAsu_KmXorKeyParams::OutKeyMetadata

Metadata of the combined key.

Its CompositeKeyId gives the destination vault and the AES sub-vault, and the slot within it, or 0 to auto-assign the first free slot. Length shall match the length of the input key splits.

Referenced by XAsu_KmValidateXorKeyParams(), and XAsu_ProvisionValidateXorParams().
