s32 XAsu_MlkemDecapsulate ( XAsu_ClientParams *  ClientParamPtr,
XAsu_MlkemEncapsDecapsParams *  MlkemParamPtr 
)

This function sends a command to ASUFW to perform ML-KEM decapsulation using the provided decapsulation (secret) key and ciphertext, producing a shared secret.

Parameters
ClientParamPtrPointer to the XAsu_ClientParams structure which holds the client input parameters.
MlkemParamPtrPointer to the XAsu_MlkemEncapsDecapsParams structure which holds the ML-KEM decapsulation parameters.
Returns
  • XST_SUCCESS, if IPI request to ASU is sent successfully.
  • XASU_INVALID_ARGUMENT, if any argument is invalid.
  • XASU_INVALID_UNIQUE_ID, if the unique ID is invalid.
  • XST_FAILURE, if sending an IPI request to ASU fails.
Note
Per FIPS 203, a ciphertext that does not match the decapsulation key yields a pseudorandom shared secret rather than an error, so that decapsulation gives an attacker no way to test ciphertexts. A successful decapsulation therefore does not mean the ciphertext was genuine. Callers must establish that through key confirmation on the derived shared secret, never by expecting a failure here.

s32 XAsu_MlkemEncapsulateDerand ( XAsu_ClientParams *  ClientParamPtr,
XAsu_MlkemEncapsDerandParams *  MlkemParamPtr 
)

This function sends a command to ASUFW to perform ML-KEM encapsulation with the message m supplied by the caller instead of drawn from the TRNG, so that the ACVP encapsulation vectors can be driven through the module.

FIPS 203 requires an approved ML-KEM.Encaps to draw m from an approved RBG, so only an ASUFW built with CAVP support serves this command; any other build rejects it as an invalid command. The encapsulation key must be passed by address, as the key vault is not available to this command.

Parameters
ClientParamPtrPointer to the XAsu_ClientParams structure which holds the client input parameters.
MlkemParamPtrPointer to the XAsu_MlkemEncapsDerandParams structure which holds the ML-KEM encapsulation parameters and the message m.
Returns

  • XASU_INVALID_ARGUMENT, if any argument is invalid.
  • XASU_INVALID_UNIQUE_ID, if the unique ID is invalid.
  • XST_FAILURE, if sending an IPI request to ASU fails.

s32 XAsu_MlkemKat ( XAsu_ClientParams *  ClientParamPtr)

This function sends a command to ASUFW to run the ML-KEM Known Answer Test, which encapsulates to and then decapsulates with a fixed NIST ACVP ML-KEM-512 vector on ASUFW and checks that the shared secrets match.

Key generation is not part of it: it carries its own pairwise consistency test instead.
