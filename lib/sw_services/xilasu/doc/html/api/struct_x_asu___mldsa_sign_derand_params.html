Detailed Description

This structure contains the parameters of the signature generation command that takes its rnd from the request, which exists for algorithm validation only (see XASU_MLDSA_SIGN_DERAND_CMD_ID).

It carries the ordinary signing parameters plus the rnd to sign with, laid out the same way XAsu_MlkemEncapsDerandParams appends the message m it encapsulates with. The secret key must be supplied through SignParams.KeyAddr: the key vault is not available to this command, so SignParams.KeyId must be zero. SignParams.Deterministic is ignored, since the supplied rnd decides the randomness outright, and RndAddr must be non-zero: an absent rnd is an error rather than a request to fall back on the TRNG.
