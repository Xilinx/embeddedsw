s32 XAsu_PlExtOperation ( XAsu_ClientParams *  ClientParamPtr,
XAsu_AesParams *  PlExtClientParamPtr 
)

This function sends command to ASUFW to perform encryption operation on a given payload data using a crypto block instantiated in the PL. 

            The whole operation is performed in a single request, hence OperationFlags and
            IsLast fields of PlExtClientParamPtr are not used. The key is taken from user
            memory.
Parameters
ClientParamPtrPointer to the XAsu_ClientParams structure which holds the client input parameters.
PlExtClientParamPtrPointer to XAsu_AesParams structure which holds the parameters of PL extension input arguments.
Returns
  • XST_SUCCESS, if IPI request to ASU is sent successfully.
  • XASU_INVALID_ARGUMENT, if any argument is invalid.
  • XASU_QUEUE_FULL, if Queue buffer is full.
  • XASU_INVALID_UNIQUE_ID, if received Queue ID is invalid.
  • XST_FAILURE, if sending an IPI request to ASU fails.

Validate the input parameters.

Validate the engine mode and the operation type supported by the PL crypto block.

Validate that IV, AAD and tag are unused for AES ECB mode on the PL path.

Validate AES key object structure parameters.

Validate the input and output data addresses and length. The minimum length of the payload is one AES block, while the maximum length can be 0x1FFFFFFC bytes, which is the ASU DMA's maximum supported data transfer length. ECB mode input data should be 16Bytes aligned.

Generate unique ID and register the callback function.

Create command header.

Update request buffer and send an IPI request to ASU.
