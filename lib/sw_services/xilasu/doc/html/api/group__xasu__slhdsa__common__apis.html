u32 XAsu_SlhdsaGetPkSize ( u8  ParamSet)

This function returns the public key size in bytes for the given SLH-DSA parameter set.

Parameters
ParamSetSLH-DSA parameter set selector (XASU_SLHDSA_PARAM_*).
Returns
Public key size in bytes (32 for 128s sets, 64 for 256s sets), or 0 if ParamSet is unsupported.

Public key size is 2n bytes: 64 for 256s sets and 32 for 128s sets. Unsupported ParamSet values return 0.

u32 XAsu_SlhdsaGetSigSize ( u8  ParamSet)

This function returns the signature size in bytes for the given SLH-DSA parameter set.

Parameters
ParamSetSLH-DSA parameter set selector (XASU_SLHDSA_PARAM_*).
Returns
Signature size in bytes (7856 for 128s sets, 29792 for 256s sets), or 0 if ParamSet is unsupported.

Signature length is fixed per parameter set (FIPS 205 Table 2). SHAKE and SHA2 share the same sizes for a given security level; unsupported selectors return 0.

s32 XAsu_SlhdsaValidateSignParams ( const XAsu_SlhdsaSignParams *  ParamsPtr)

This function validates SLH-DSA sign parameters.

Parameters
ParamsPtrPointer to XAsu_SlhdsaSignParams.
Returns
  • XST_SUCCESS, if validation succeeds.
  • XST_INVALID_PARAM, if any field is invalid (NULL pointer, zero addresses, invalid ParamSet, CtxLen/CtxAddr mismatch, MsgLen exceeds DMA limit, SignatureLen mismatch, or SkLen not equal to the ParamSet secret-key size).

Validate input pointer.

Validate the parameter set first, since the expected signature size and the required pre-hash function are both derived from it.

Validate the context length against the FIPS 205 limit of 255 bytes.

Validate that a context address is supplied whenever a non-empty context is used.

Bound the message length by what the ASU DMA can transfer in a single operation, as the message is fed to the hash engine without being split.

The secret key, message and signature addresses are all mandatory, so a zero address in any of them is rejected before ASUFW dereferences it.

The secret key is a fixed length per parameter set, so SkLen must match exactly. A caller declaring any other length has not supplied the whole key.

SLH-DSA signatures are a fixed length per parameter set, so SignatureLen must match exactly. This is what guarantees the output buffer is large enough to be written.

Validate the pure versus pre-hash message mode, and in pre-hash mode that HashId is the one required by the parameter set and MsgLen is the matching digest length.

Validate the sign mode, which selects hedged or deterministic signing.

s32 XAsu_SlhdsaValidateSignVerifyParams ( const XAsu_SlhdsaSignVerifyParams *  ParamsPtr)

This function validates SLH-DSA signature verification parameters.

Parameters
ParamsPtrPointer to XAsu_SlhdsaSignVerifyParams.
Returns
  • XST_SUCCESS, if validation succeeds.
  • XST_INVALID_PARAM, if any field is invalid (NULL pointer, zero addresses, invalid ParamSet, CtxLen/CtxAddr mismatch, MsgLen exceeds DMA limit, SignatureLen mismatch, or PubKeyLen not equal to the ParamSet public key size).

Validate input pointer.

Validate the parameter set, which fixes the expected signature and public key sizes.

Validate the context length against the FIPS 205 limit of 255 bytes.

Validate that a context address is supplied whenever a non-empty context is used. Both CtxLen and CtxAddr must reproduce the values used at signing time, because the context is bound into the message digest.

Bound the message length by the maximum single ASU DMA transfer length.

The public key, message and signature addresses are all mandatory for verification.

Reject a signature whose length does not match the parameter set, so that a truncated or oversized signature is never parsed as if it were well formed.

The public key is a fixed length per parameter set, so PubKeyLen must match exactly. Verification always reads the whole key, so a shorter declared length would leave part of it unvalidated.

Validate the message mode and, for pre-hash mode, the HashId and digest length.
