s32 XAsu_MlkemValidateEncapsDerandParams ( const XAsu_MlkemEncapsDerandParams *  MlkemParamsPtr)

This function validates the parameters of the ML-KEM encapsulation which takes the message m from the request, an algorithm validation only service.

Parameters
MlkemParamsPtrPointer to the XAsu_MlkemEncapsDerandParams structure which holds the ML-KEM encapsulation parameters and the message m.
Returns
  • XST_SUCCESS, if validation of ML-KEM parameters is successful.
  • XST_FAILURE, if any argument is invalid.

Validate ML-KEM params pointer.

Validate the parameters this command shares with encapsulation.

The encapsulation key comes from KeyAddr only, as the key vault is not reachable from a validation command.

m must be supplied: a zero address is an error here rather than a request to draw from the TRNG.

s32 XAsu_MlkemValidateParams ( const XAsu_MlkemEncapsDecapsParams *  MlkemParamsPtr)

This function validates the ML-KEM encapsulation/decapsulation parameters.

Parameters
MlkemParamsPtrPointer to the XAsu_MlkemEncapsDecapsParams structure which holds the ML-KEM encapsulation/decapsulation parameters.
Returns
  • XST_SUCCESS, if validation of ML-KEM parameters is successful.
  • XST_FAILURE, if any argument is invalid.

Validate ML-KEM params pointer.

Validate the parameter set against the FIPS 203 approved sets.

Validate ciphertext address, which is the output for encaps and the input for decaps.

Validate the shared secret address and buffer length, which is an output of both operations and is 32 bytes for every parameter set.

Validate that exactly one of KeyAddr or KeyId is provided, and that a vault sourced key carries no length.
