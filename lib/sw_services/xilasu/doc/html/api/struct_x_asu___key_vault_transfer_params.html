Detailed Description

This structure contains info for exporting and importing key vault.

Field Documentation

u32 XAsu_KeyVaultTransferParams::BufSize

Buffer size for export or actual data size for import.

Referenced by XAsu_KmExportKeyVault(), and XAsu_KmImportKeyVault().

u8 XAsu_KeyVaultTransferParams::Context[XASU_KM_KV_CONTEXT_SIZE_IN_BYTES]

Context the key vault keys are derived from.

An import only recovers a blob when given the same context the export used.

Referenced by XAsu_KmExportKeyVault(), and XAsu_KmImportKeyVault().

u64 XAsu_KeyVaultTransferParams::DataAddr

Address for vault data (export destination or import source).

Referenced by XAsu_KmExportKeyVault(), and XAsu_KmImportKeyVault().

u64 XAsu_KeyVaultTransferParams::ExportResultAddr

Address of the export result block (export only).

Must point to an XAsu_KeyVaultExportResult, which the client library fills from the command response with the blob size and the modified flag.

Referenced by XAsu_KmExportKeyVault().

u32 XAsu_KeyVaultTransferParams::RevokeEfuseNum

Off-chip revocation eFuse number the blob is bound to (export only).

Blowing that eFuse is what retires the blob, and an import refuses a blob whose eFuse is blown.

Referenced by XAsu_KmExportKeyVault().
