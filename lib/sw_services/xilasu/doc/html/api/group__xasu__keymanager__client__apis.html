Parameters

KmSubVaultParamPtrPointer to XAsu_KeyManagerPqcKeyGenParams structure which holds the parameters of KeyVault input arguments. The ML-DSA parameter set is passed in KmParams.KeyMetadata.KeyAttributes and the public key length in KmParams.KeyMetadata.Length. A non-zero SeedAddr derives the pair from that seed instead of one drawn from the TRNG.   • Second key ID will be the private key ID

XAsu_KeyManagerPqcKeyGenParams *  KmSubVaultParamPtr 
)

This function sends a command to ASUFW to perform ML-KEM key pair generation for the requested subsystem.

Parameters
ClientParamPtrPointer to the XAsu_ClientParams structure which holds the client input parameters.
KmSubVaultParamPtrPointer to XAsu_KeyManagerPqcKeyGenParams structure which holds the parameters of KeyVault input arguments. The ML-KEM parameter set is passed in KmParams.KeyMetadata.KeyAttributes and the encapsulation key length in KmParams.KeyMetadata.Length. A non-zero SeedAddr derives the pair from that 64-byte d || z seed instead of one drawn from the TRNG. When the pair is stored, KmParams.KeyMetadata.CompositeKeyId selects the vault and the slot index requested in both the decapsulation and the encapsulation sub-vault, or zero to take the first free slot in each.
Returns
  • XST_SUCCESS, if IPI request to ASU is sent successfully.
  • XASU_INVALID_ARGUMENT, if any argument is invalid.
  • XASU_QUEUE_FULL, if Queue buffer is full.
  • XST_FAILURE, if sending an IPI request to ASU fails.

Validation of inputs.

Validate the seed and the parameter set against the same contract the server validates them against, so that the request is rejected here rather than after an IPI round trip.

Generate a unique ID and register the callback function. Two key IDs are returned: the encapsulation key ID first, then the decapsulation key ID.

Create command header.

Update request buffer and send an IPI request to ASU.
