s32 XAsu_MldsaKat ( XAsu_ClientParams *  ClientParamPtr)

This function sends a command to ASUFW to run the ML-DSA Known Answer Test, which signs and then verifies a fixed NIST ACVP ML-DSA-44 vector on ASUFW.

Key generation is not part of it: it carries its own pairwise consistency test instead.

  • XASU_INVALID_UNIQUE_ID, if the unique ID is invalid.
  • XST_FAILURE, if sending an IPI request to ASU fails.

s32 XAsu_MldsaSignDerand ( XAsu_ClientParams *  ClientParamPtr,
XAsu_MldsaSignDerandParams *  MldsaParamPtr 
)

This function sends a command to ASUFW to generate an ML-DSA signature with the signing randomness rnd supplied by the caller instead of drawn from the TRNG, so that the ACVP hedged signature vectors can be driven through the module.

Hedged signing draws rnd from an approved RBG, so only an ASUFW built with CAVP support serves this command; any other build rejects it as an invalid command. The secret key must be passed by address, as the key vault is not available to this command, and the Deterministic field is ignored because the supplied rnd decides the randomness outright.

Parameters
ClientParamPtrPointer to the XAsu_ClientParams structure which holds the client input parameters.
MldsaParamPtrPointer to the XAsu_MldsaSignDerandParams structure which holds the ML-DSA signature generation parameters and the rnd to sign with.
Returns

  • XASU_INVALID_ARGUMENT, if any argument is invalid.
  • XASU_INVALID_UNIQUE_ID, if the unique ID is invalid.
  • XST_FAILURE, if sending an IPI request to ASU fails.
