xasu_slhdsa.c File Reference

Overview

This file contains the implementation of the client interface functions for the SLH-DSA (FIPS 205) module.

Each API validates the client-supplied parameters, registers a completion callback, builds the command header and forwards the request to ASUFW over IPI.

Key pair generation is not an SLH-DSA module command: it is requested through the key manager, using XAsu_KmGenerateSlhdsaKeyPair. All 64-bit addresses in the parameter structures must point to memory visible to both the client and ASUFW, and those buffers must remain valid until the registered callback reports completion.
