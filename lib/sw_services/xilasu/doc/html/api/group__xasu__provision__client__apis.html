s32 XAsu_DeleteDevProvisionCert ( XAsu_ClientParams *  ClientParamPtr)

This function sends a command to ASUFW to delete the calling subsystem's provisioning key pairs backing the Device Provisioning Certificate (SAS section 12.16.3). 

    The provisioning authentication and wrapping key pairs are removed from the internal
    exportable key vault so that the next XAsu_GetDevProvisionCert call regenerates them.

ClientParamPtrPointer to the XAsu_ClientParams structure which holds the client input parameters.
Returns
  • XST_SUCCESS, if the IPI request to ASUFW is sent successfully.
  • XASU_INVALID_UNIQUE_ID, if the received Queue ID is invalid.

Validate client parameters.

Generate a unique ID and register the callback function.

Create command header.

Send an IPI request to ASUFW.

s32 XAsu_GetDevProvisionCert ( XAsu_ClientParams *  ClientParamPtr,
XAsu_DevProvisionCertParams *  ParamsPtr 
)

This function sends a command to ASUFW to generate and return the Device Provisioning Certificate (DPC) for the calling subsystem (SAS section 12.16.2). 

    The ASU checks the internal exportable key vault for the subsystem's provisioning
    authentication key pair (ECC NIST P-384) and provisioning wrapping key pair (ECIES
    over NIST P-384). Any pair that is missing is generated with the TRNG and stored in
    the exportable vault. A UDE-signed X.509 certificate is generated over each public
    key, the DPC container (Device DNA, both certificates and a UDE signature over them)
    is assembled and returned to the caller at ParamsPtr->DpcBufAddr with its actual size
    at ParamsPtr->DpcActualSizeAddr.
Parameters
ClientParamPtrPointer to the XAsu_ClientParams structure which holds the client input parameters.
ParamsPtrPointer to the XAsu_DevProvisionCertParams structure which holds the DPC generation input arguments.
Returns
  • XST_SUCCESS, if the IPI request to ASUFW is sent successfully.
  • XASU_INVALID_ARGUMENT, if any argument is invalid.
  • XASU_INVALID_UNIQUE_ID, if the received Queue ID is invalid.

Validate the provisioning input parameter pointer.

Validate client parameters.

Validate the DPC generation input parameters.

Generate a unique ID and register the callback function, providing the caller's DpcActualSizeAddr as the response buffer so the DPC size returned by the server is copied there during the callback.

Create command header.

Update request buffer and send an IPI request to ASUFW.

s32 XAsu_ProvisionUde ( XAsu_ClientParams *  ClientParamPtr,
XAsu_ProvisionUdeParams *  ParamsPtr 
)

This function sends a command to ASUFW to provision a Unique Device Endorsement (UDE) key pair. 

    The UDE key pair (ECC NIST P-384) is generated inside the ASU so the private key is
    never exposed outside the ASU. The private key is encrypted with the PUF KEK and
    programmed into the requested eFUSE slot by the ASU (via the PLM), and a self-signed
    X.509 certificate over the generated public key is returned to the caller at
    ParamsPtr->CertBufAddr with its actual size at ParamsPtr->CertActualSizeAddr.
Parameters
ClientParamPtrPointer to the XAsu_ClientParams structure which holds the client input parameters.
ParamsPtrPointer to the XAsu_ProvisionUdeParams structure which holds the UDE key provisioning input arguments.

  • XASU_INVALID_ARGUMENT, if any argument is invalid.
  • XASU_INVALID_UNIQUE_ID, if the received Queue ID is invalid.
  • XST_FAILURE, in case of failure.

Validate client parameters.

Validate the UDE provisioning input parameters.

Generate a unique ID and register the callback function, providing the caller's CertActualSizeAddr as the response buffer so the certificate size returned by the server is copied there during the callback.

s32 XAsu_ProvisionUserEfuse ( XAsu_ClientParams *  ClientParamPtr,
XAsu_ProvisionUserEfuseParams *  ParamsPtr 
)

This function sends a command to ASUFW to program a USER eFUSE key. 

    The key to be programmed can be sourced from the AKV, generated internally by the
    ASU using the TRNG (benign provisioning), or supplied directly by the user.
    USER_EFUSE_KEY_0 is always stored in black (PUF KEK encrypted) form.
    USER_EFUSE_KEY_1 is stored in the form selected by ParamsPtr->KeyForm (black or
    red). Red USER key 1 can be used by both PLM and ASU. Black USER key 1 is
    subsystem-exclusive; use black provisioning with the intended end use case in mind.
Parameters
ClientParamPtrPointer to the XAsu_ClientParams structure which holds the client input parameters.
ParamsPtrPointer to the XAsu_ProvisionUserEfuseParams structure which holds the USER eFUSE key provisioning input arguments.
Returns

  • XASU_INVALID_ARGUMENT, if any argument is invalid.
  • XASU_INVALID_UNIQUE_ID, if the received Queue ID is invalid.
  • XST_FAILURE, in case of failure.

XAsu_UnwrapProvisionInstructionsParams *  ParamsPtr

This function sends a command to ASUFW to process a wrapped provisioning image header.

The ASU validates the header, resolves the subsystem's authentication public key internally, verifies the signature, ECIES-decrypts and CMAC-KDF-derives the chunk key, then executes the recovered provisioning instructions.
