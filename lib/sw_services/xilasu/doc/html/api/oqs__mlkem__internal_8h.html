oqs_mlkem_internal.h File Reference

Overview

This header is the ASU firmware CONTRACT for the lower-level (native) ML-KEM entry points exposed by the liboqs "mlkem-native" backend.

liboqs's generic OQS_KEM API reaches these same functions indirectly, through a descriptor object that OQS_KEM_new() looks up by algorithm name and allocates on the heap. The firmware calls the native symbols directly instead, so that the ML-KEM path needs no allocator, and so that the name-keyed registry, which references every algorithm liboqs was built with, does not defeat –gc-sections and anchor unused backends.

These prototypes MUST match the symbols exported by liboqs.a exactly. The exact link-level names were verified via nm liboqs.a and follow the pattern: PQCP_MLKEM_NATIVE_MLKEM{512|768|1024}_C_<function>

The build of liboqs used here does NOT define MLK_CONFIG_CONTEXT_PARAMETER, therefore the functions have NO trailing application-context argument. Defining it would add that argument without changing a single symbol name, so the mismatch would link silently. build_liboqs.sh checks for exactly that before it builds: it compiles these declarations alongside mlkem-native's own, where a disagreement is a compile error. Keep the two in step, and see README.liboqs.md section 2 if that check fires.

NOTE: The liboqs drop agent must ensure these symbols are exported (not stripped) from liboqs.a. This header is the single source of truth; the drop must conform to it.

This function performs ML-KEM-1024 decapsulation, recovering the shared secret from the given ciphertext. 


Parameters

  

    
SharedSecretPointer to the buffer which holds the recovered shared secret. It must be at least MLKEM_SSBYTES long. 

    
CipherTextPointer to the ciphertext. 

    
SecKeyPointer to the secret (decapsulation) key.

  

  




Returns
    

  • 0 on success. A ciphertext that does not match the key yields the implicit rejection shared secret rather than an error, as specified by FIPS 203.
    • 

  • Non-zero mlkem-native error code on failure.
