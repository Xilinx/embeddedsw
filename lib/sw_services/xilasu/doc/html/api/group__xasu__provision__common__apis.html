s32 XAsu_ProvisionValidateUserEfuseParams ( const XAsu_ProvisionUserEfuseParams *  ParamsPtr)

This function validates the USER eFUSE key provisioning parameters.

Parameters
ParamsPtrPointer to the XAsu_ProvisionUserEfuseParams structure which holds the USER eFUSE key provisioning input arguments.
Returns
  • XST_SUCCESS, if the parameters are validated successfully.
  • XST_FAILURE, if the parameters validation fails.

Validate the target eFUSE key identifier.

Validate the key length (only 256-bit keys are supported by USER eFUSE keys).

USER_EFUSE_KEY_0 is the ASU KEK seed and is black only. USER_EFUSE_KEY_1 may be black or red.

Validate the key source, its corresponding KeyId/KeyAddr fields, and the key source against the destination eFUSE.

ASU generates the key; no KeyId/KeyAddr must be supplied.

Vault source: rejected for eFUSE0; KeyId non-zero, KeyAddr zero.

Buffer source: rejected for eFUSE0; KeyAddr non-zero, KeyId zero.

References XAsu_ProvisionUserEfuseParams::EfuseKeyId, XAsu_ProvisionUserEfuseParams::KeyAddr, XAsu_ProvisionUserEfuseParams::KeyForm, XAsu_ProvisionUserEfuseParams::KeyId, XAsu_ProvisionUserEfuseParams::KeyLen, XAsu_ProvisionUserEfuseParams::KeySource, XASU_EFUSE_BLACK_KEY, XASU_EFUSE_RED_KEY, XASU_PROVISION_EFUSE_USER_KEY_0, XASU_PROVISION_EFUSE_USER_KEY_1, XASU_PROVISION_KEY_SOURCE_ASU_GENERATED, XASU_PROVISION_KEY_SOURCE_USER_BUFFER, XASU_PROVISION_KEY_SOURCE_VAULT, and XASU_PROVISION_USER_EFUSE_KEY_SIZE_IN_BYTES.
