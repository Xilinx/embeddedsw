Detailed Description

XPm_GicProxy - Structure containing GIC Proxy properties Pointer to the array of GIC Proxy Groups Number of elements in the array of GIC Proxy Groups Clear all set wake-up sources (Flags for all Groups) Function that Enables GIC Proxy and all interrupts that are set as wake sources.

Returns XST_SUCCESS or an error code. GIC Proxy Flags (is Enabled or not)
