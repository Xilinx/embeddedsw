xpm_memtbl.h File Reference

Overview

Memory-range reachability table in PMC RAM.

A static, sorted subsystem->memory-region table is populated in PMC RAM (at XPLMI_MEMTBL_ADDR) by the configuration tooling. PLM is the sole writer of the runtime-mutable fields - each row's State (Active/Inactive reachability) and the header UpdateCounter seqlock - so that consumers (e.g. ASU firmware) see correct region reachability. PLM only produces the table; it does not consume it for its own address validation.

Table layout (little-endian words in PMC RAM): word0 : NumEntries[31:16] | EntrySize[15:12]=0x4 | HeaderSize[11:8]=0x2 | Version[7:0] word1 : UpdateCounter (seqlock; odd => mutation in progress) entry[i] (16 B each, EntrySize = 4 words): +0x0 Attr : State[31:28] | MemFlags[27:24] | Reserved[23:16] | AccessPerm[15:0] +0x4 Size : region size in 4KB units (ActualBytes = Size << 12) +0x8 AddrHigh : region address [63:32] +0xC AddrLow : region address [31:0]

Present-detection for the memory-range table (no-op fallback).

Platforms without a mem-table reservation never carry a table, so this stub always reports "absent".

Returns
0U always (table never present on this platform).
