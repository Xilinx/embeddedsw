xpm_memtbl.c File Reference

Overview

Memory-range reachability table writer.

PLM is the sole writer of the runtime-mutable table fields:

  • per-row State (Active/Inactive region reachability)
  • header UpdateCounter (seqlock guarding torn reads)

Reachability is recomputed for all valid rows on any relevant event (seed pass after PMC CDO, OCM/TCM/DDRMC device state change, PLD power event, PL init-finish). The hooks only READ live node/power state and WRITE the table - they never issue an EEMI/PM call (recursion) and are idempotent. PLM produces the table only; it does not consume it for its own address validation.

Note
Gated for the versal_2ve_2vm platform via XPLMI_MEMTBL_ADDR, which is only defined in versal_2ve_2vm/xplmi_hw.h. xilpm_ng is a versal_2ve_2vm-only (server) library, matching neighboring code that references XPLMI_* PMC-RAM constants unguarded.
