Pack one config word per selected detector, then send a single XLoader_ConfigureGlitchDetector IPI. PMC calibration is applied live in GD_FUSE_CTRL, while the ASU and LPD detectors are held in reset by the PLM while calibration is written and released afterwards. Enabling / test-glitch are left to the application (optional TEST_GLITCH_* path below).

Configure the DDR address of the PDI for the next image load. PLM validates the address range and stores it if valid. On failure the address is marked invalid and PLM falls back to the Image Store PDI list.
