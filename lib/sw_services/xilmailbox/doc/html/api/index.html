xilmailbox Documentation

The XilMailbox library provides the top-level hooks for sending or receiving an inter-processor interrupt (IPI) message using the Zynq® UltraScale+ MPSoC IPI hardware. For a full description of IPI features, see the hardware specification. This library supports the following features:

  • Triggering an IPI to a remote agent.
  • Sending an IPI message to a remote agent.
  • Callbacks for error and receive IPI events.
  • Reading an IPI message.

Software Initialization

  • The XMailbox_Initialize() function initializes IPI. This step initializes a library instance for the given IPI channel.
  • The XMailbox_Send() function triggers an IPI to a remote agent.
  • The XMailbox_SendData() function sends an IPI message to a remote agent. The message type should be either XILMBOX_MSG_TYPE_REQ or XILMBOX_MSG_TYPE_RESP.
  • The XMailbox_Recv() function reads an IPI message from a specified source agent. The message type should be either XILMBOX_MSG_TYPE_REQ or XILMBOX_MSG_TYPE_RESP.
  • Use the XMailbox_SetCallBack() function to register callbacks for receive and error events.
