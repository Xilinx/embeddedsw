diskio.c File Reference

Overview

Implements the glue layer between the file system and the driver.

Description related to the SD driver: To use the file system with SD, select xilffs in the Software Development Kit (SDK) when creating a board support package (BSP). In SDK, set "fs_interface" to 1 to select the SD interface. You can currently use this glue layer with only one SD controller enabled. To use an embedded MultiMediaCard (eMMC), set "Enable MMC" to 1 in SDK. Otherwise, the glue layer uses SD by default.

Description: This glue layer initializes the host controller and SD card in disk_initialize. If the SD card supports them, it enables 4-bit mode and high speed mode. The default block size is 512 bytes. The disk_read and disk_write functions read and write files using Advanced DMA version 2 (ADMA2) in polled mode. The file system can read from and write to an SD card that is already formatted as FATFS.

          DSTATUS disk_initialize 
          (
          BYTE 
          pdrv)
          
        

      





Initializes the drive. 


For SD, this function initializes the host controller and the card. This function also selects additional settings such as bus width, speed, and block size.


Parameters

  

    
[in]pdrvDrive number.

  

  




Returns
Drive status. A value of 0 or STA_PROTECT alone indicates successful initialization. The status is a bitwise OR of the following flags.
    

  • STA_NODISK if the disk is not present.
    • 

  • STA_NOINIT if the drive is not initialized.
    • 

  • STA_PROTECT if the drive is write protected. 
    •

          pdrv)
          
        

      





Gets the status of the disk. 


For SD, this function checks whether the card is present.


Parameters

  

    
[in]pdrvDrive number.

  

  




Returns
    

  • 0 if the status is OK.
    • 

  • STA_NOINIT if the drive is not initialized.
    • 

  • STA_NODISK if there is no medium in the drive.
    • 

  • STA_PROTECT if the drive is write protected.
    • 





Note
If the card detect signal is not connected, this function cannot check whether the card is present.
