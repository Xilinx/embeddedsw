xilffs_polled_example.c File Reference

Overview

Writes to and reads from an SD card through the file system.

Note
This example uses the file system with SD to write to and read from an SD card using Advanced DMA version 2 (ADMA2) in polled mode. To test this example, the file system must not be in read-only mode. To test this example, the USE_MKFS option must be true.

This example was tested using an SD2.0 card and eMMC (using an eMMC to SD adapter).

To test with different logical drives, specify the drive number in both the FileName and Path variables. By default, the example uses drive 0 if the FileName variable does not specify a drive number. For example, to test logical drive 1, set FileName = "1:/<file_name>" and Path = "1:/". Similarly, to test logical drive N, set FileName = "N:/<file_name>" and Path = "N:/".
