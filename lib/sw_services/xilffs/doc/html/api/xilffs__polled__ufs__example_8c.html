xilffs_polled_ufs_example.c File Reference

Overview

Writes to and reads from a UFS device through the file system.

Note
This example uses the file system with Universal Flash Storage (UFS) to write to and read from a UFS device in polled mode. To test this example, the file system must not be in read-only mode. To test this example, the USE_MKFS option must be true.

This example was tested using a UFS device.

To test with different logical drives, specify the drive number in both the FileName and Path variables. By default, the example uses drive 0 if the FileName variable does not specify a drive number. For example, to test logical drive 2, set FileName = "2:/<file_name>" and Path = "2:/". Similarly, to test logical drive N, set FileName = "N:/<file_name>" and Path = "N:/".
