xilsfl_ospi_flash_readwrite_example.c File Reference

Overview

Demonstrates erase, write, and read with the serial flash library.

This file contains a design example using the serial flash library (SFL). The hardware on which this example runs must have an octal serial NOR flash.

This example has been tested with the Micron Octal Serial Flash (MT35XU02GCBA).
