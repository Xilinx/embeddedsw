xilsfl_micron_asp.c File Reference

Overview

Implements Micron advanced sector protection for OCTAL and QUAD NOR.

This file implements Micron Advanced Sector Protection (ASP) for OCTAL OSPI and QUAD QSPI NOR. It covers volatile locks, nonvolatile (NV) locks, the Sector Protection Register, password register sequences, and erasing nonvolatile lock bits. It uses the framing expected when XSfl_AspMicronOctalAspOpsTable binds at initialization. The Flash Configuration Table selects the transfer protocol. The same ASP sequences therefore drive both OCTAL (Micron ID 0x2C) and QUAD (Micron ID 0x20) parts.

This module never caches the password supplied by the application in static RAM. Verification reads the on-device password with READ PASSWORD and compares it to the caller transient buffer for each authenticated operation.

NOTE ON RETENTION (datasheet): Micron documents PASSWORD PROGRAM timing (tPASSP) and PASSWORD PROTECTION PROGRAM operations. Password bits can remain programmed across power cycles depending on device configuration (factory default is typically erased). Confirm retention on your silicon step before relying on power-off clearing. Volatile sector locks (E1/E0) still clear at reset.
