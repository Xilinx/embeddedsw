xilsfl_micron_asp.h File Reference

Overview

Defines the Micron MT35 ASP vendor-private opcodes and constants.

Micron MT35 OCTAL/QUAD NOR Advanced Sector Protection (ASP) vendor-private opcodes and constants. These are the command opcodes, dummy cycle counts, password width, and the Sector Protection Register (SPR) one-time programmable (OTP) lock bit. Only xilsfl_micron_asp.c includes this file, and it is not part of the public xilsfl API.
