xsecure_libver.c File Reference

Overview

This file contains the client-side implementation of the XilSecure library version compatibility check.

It queries the server (PLM) library version over the IPI mailbox and compares it against the client's compile-time version.

Queries the XilSecure server (PLM) library information - version and capability bitmaps - by issuing a Features command with an always-present crypto api-id. 


Parameters

  

    
InstancePtrPointer to the client instance (mailbox handle + SlrIndex). 

    
LibInfoPointer to a Xil_LibInfo structure that receives the server library version (LibVersion) and capability bitmap words.

  

  




Returns
    

  • XST_SUCCESS - On success
    • 

  • XST_INVALID_PARAM - If InstancePtr or LibInfo is NULL
    • 

  • Error - On SMC/mailbox transport failure or if the Features command fails
    • 





Note
The Features command is sent with a valid crypto api-id so the server command SUCCEEDS and returns the full response buffer, in which the library version/capability are reported at fixed indices ([3]/[4]). A server too old to report capabilities leaves those words at 0, which the caller reads as "no
        capability advertised" - the safe default. 



References XSECURE_API_FEATURES, XSECURE_API_SHA3_OPERATION, XSECURE_API_SHA3_UPDATE, XSecure_SendRequest(), and XSECURE_SLR_INDEX_SHIFT.

Verifies that the client XilSecure library is compatible with the running server (PLM) XilSecure library. 


    The client compile-time version (XSecure_GetLibVersion()) is compared against the
    version reported by the server. Compatibility requires the major versions to match
    and the client minor version to be less than or equal to the server minor version
    (a newer server stays backward compatible with an older client).

Parameters

  

    
InstancePtrPointer to the client instance (mailbox handle + SlrIndex).

  

  




Returns
    

  • XST_SUCCESS - Client and server library versions are compatible
    • 

  • XSECURE_LIB_VERSION_MAJOR_MISMATCH - Major versions differ (breaking change)
    • 

  • XSECURE_LIB_VERSION_MINOR_MISMATCH - Client minor is newer than the server
    • 

  • XST_INVALID_PARAM / Error - On transport failure while querying the server 
    •
