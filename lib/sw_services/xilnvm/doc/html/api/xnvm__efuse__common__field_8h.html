xnvm_efuse_common_field.h File Reference

Overview

eFuse band-engine field types, flags, band macros, and shared extern symbols.

Band/protection/field table definitions: xnvm_efuse_plat_field.h (per platform). Included from xnvm_efuse_engine.c, xnvm_ops.c, and plat sources via common_field.h.

#include "xil_types.h"
#include "xil_util.h"
#include "xnvm_common_defs.h"
#include "xnvm_efuse_common.h"
