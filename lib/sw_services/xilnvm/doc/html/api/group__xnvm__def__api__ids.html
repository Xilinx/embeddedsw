enum XNvm_AesKeyType

Enum for Aes key types.

Key types from XNVM_EFUSE_AES_KEY_2ND onwards address the independent secondary eFUSE slots of Versal_2Ve_2Vm and Versal_2Vp_P. The server routes every key type at or above that value to the platform layer, so these values must stay last.
