int XCert_GenerateX509Cert ( u64  X509CertAddr,
u32  MaxCertSize,
u32 *  X509CertSize,
XCert_Config *  Cfg 
)

This function creates the X.509 Certificate/Certificate Signing Request(CSR)

Parameters
X509CertAddrAddress of the X.509 Certificate buffer
MaxCertSizeMaximum size of the X.509 Certificate buffer
X509CertSizeSize of X.509 Certificate in bytes
CfgPointer to structure which includes configuration for the X.509 Certificate.
Returns
  • XST_SUCCESS Successfully generated X.509 certificate/CSR
  • XST_INVALID_PARAM Invalid function arguments
  • XCERT_ERR_X509_KAT_FAILED Failure of SHA384 KAT
  • XCERT_ERR_X509_GEN_TBSCERT_DIGEST Failure in SHA 384 digest calculation for TBS certificate
  • XCERT_ERR_X509_GET_SIGN Failure in getting stored signature
  • XSECURE_KAT_MAJOR_ERROR Failure in Sign Generate KAT
  • XCERT_ERR_X509_CALC_SIGN Failure in generating ephemeral key and signature
  • XCERT_ERR_X509_UPDATE_ENCODED_LEN Failure in updating encoded length
  • XCERT_ERR_X509_INSUFFICIENT_MEMORY Insufficient buffer provided for X.509 cert.
  • XST_FAILURE In case of failure
Note
Certificate ::= SEQUENCE { tbsCertificate TBSCertificate, signatureAlgorithm AlgorithmIdentifier, signatureValue BIT STRING }

SHA 384 is used to calculate hash for Serial field and to calculate hash for signature calculation. So run KAT for SHA384 before use

Generate Sign Algorithm field

Calculate SHA 384 Digest of the TBS certificate

Get the TBS certificate signature stored in Cert DB

If the Signature is available, compare the hash stored with the hash calculated to make sure nothing is changed. if hash matches, copy the stored signature else generate the signature again.

If the Signature is not available or Hash comparison from above fails, regenerate the signature.

Calculate signature of the TBS certificate using the private key

Copy the generated signature and hash into SignStore

Generate Signature field

Update the encoded length in the X.509 certificate SEQUENCE

Validate the certificate size and copy the certificate to user buffer

int XCert_StoreCertUserInput ( u32  SubSystemId,
XCert_UserCfgFields  FieldType,
u8 *  Val,
u32  Len,
u32  KeyIndex 
)

This function stores the user provided value for the user configurable fields in the certificate as per the provided FieldType.

Parameters
SubSystemIdId of subsystem for which field data is provided
FieldTypeTo identify the field for which input is provided
ValValue of the field provided by the user
LenLength of the value in bytes
KeyIndexIndex of the key for given subsystem ID
Returns
  • XST_SUCCESS If whole operation is success
  • XST_INVALID_PARAM Failure due to invalid arguments
  • XOCP_ERR_X509_USER_CFG_STORE_LIMIT_CROSSED Exceed maximum limit of user configuration
  • XST_FAILURE Upon any failure

Look for the Subsystem Id. If it is there get the index and update the field of existing subsystem else increment index and add entry for new subsystem.
